## 확정된 공통 사항

- 엔진: Godot 4.7 .NET(C#). 대상 플랫폼: PC(Windows)와 안드로이드. 화면: 가로 1280x720 기준(`expand`로 화면비에 맞게 늘어남).
- **랭킹**: 게임마다 PC(기기) 로컬에 Top 10을 저장하고, 게임을 껐다 켜도 유지한다(`user://records.json`).
  - Top 10에 들면 이름을 등록한다. 최근에 쓴 이름(최대 3개)이 큰 버튼으로 나와서 한 번 누르면 된다. 새 이름은 "새 이름" 버튼을 눌러 키보드로 입력한다(최근 이름이 없으면 바로 입력 칸). 비워 두면 "친구"로 저장한다.
  - 정렬 기준: 풍선·과일·공룡은 점수 높은 순. 짝 맞추기는 걸린 시간 짧은 순(같으면 뒤집은 횟수 적은 순). 퀴즈는 맞힌 개수 많은 순, 미로는 모은 별 많은 순, 둘 다 같으면 시간 짧은 순. 동점이면 먼저 세운 기록이 위다.
  - **난이도별 랭킹**: 설정에 따라 결과를 비교할 수 없는 게임은 난이도마다 Top 10을 따로 둔다(퀴즈, 짝 맞추기, 미로: 쉬움/보통/어려움). 결과 화면은 방금 한 난이도의 순위를, 기록 화면은 난이도 탭을 보여 준다. 메인 메뉴 카드에는 기록이 있는 가장 어려운 난이도의 최고 기록이 나온다. 꾸미기 옵션(배경, 캐릭터 등)이나 문제 종류로는 나누지 않는다. 짝 맞추기(카드 수)와 미로(크기)도 이 방식을 쓴다. 미로는 같은 난이도의 미로 여러 개가 한 표를 같이 쓴다.
  - 점수가 0인 판은 기록하지 않는다(미로는 탈출하면 별 0개여도 기록한다).
  - 메인 메뉴의 "기록" 화면에서 게임별 Top 10을 볼 수 있다.

## 전체 프로젝트 구조

6개의 게임을 완전히 별도 앱으로 만드는 것보다 하나의 미니게임 앱 안에 묶는 구조를 권장한다.

```text
Kids Mini Game
│
├─ 메인 메뉴
│   ├─ 풍선 터뜨리기
│   ├─ 과일 받기
│   ├─ 동물 짝 맞추기
│   ├─ 미로 탈출
│   ├─ 숫자 / 색깔 퀴즈
│   └─ 공룡 점프
│
├─ 캐릭터 선택
├─ 배경 선택
├─ 설정
│   ├─ BGM 볼륨
│   └─ 효과음 볼륨
│
└─ 기록
    ├─ 풍선 최고 점수
    ├─ 과일 최고 점수
    ├─ 짝 맞추기 최고 기록
    ├─ 미로 최고 기록
    ├─ 퀴즈 최고 점수
    └─ 공룡 점프 최고 점수
```

### 공통 시스템

가능하면 다음 기능은 여러 게임에서 재사용한다.

- GameManager 기본 구조
- AudioManager
- Scene 전환
- 캐릭터 선택 데이터
- 배경 선택 데이터
- BGM / 효과음 설정
- 최고 기록 저장
- 결과 화면
- 공통 버튼 UI


## 권장 구현 순서

AI를 이용해 구현할 경우 6개 게임을 한 번에 만들기보다 하나씩 완성하는 것을 권장한다.

추천 순서:

1. **풍선 터뜨리기**
2. **과일 받기**
3. **숫자 / 색깔 퀴즈**
4. **동물 짝 맞추기**
5. **미로 탈출**
6. **공룡 점프**

풍선 터뜨리기에서 먼저 다음 핵심 기능을 완성할 수 있다.

- 타이머
- 점수
- 랜덤 오브젝트 생성
- 클릭 / 터치 입력
- 효과음
- 애니메이션
- 난이도 증가
- 결과 화면
- 최고 기록

이 기반을 만든 뒤 다른 미니게임을 추가하면 개발 속도를 크게 높일 수 있다.

### 새 게임(7~18번) 구현 순서

원본 확장 기획서의 권장 순서를 따른다. 앞 게임에서 만든 것을 뒤 게임이 다시 쓰도록 짠 순서다.

1. **숫자 합치기**: 격자 판, 스와이프 입력, 되돌리기
2. **애벌레 냠냠**: 격자 이동, 방향 입력(미로 탈출 버튼 재사용)
3. **아기새 날기**: 한 버튼 물리(공룡 점프 구조 재사용)
4. **벽돌깨기**: 공 반사·충돌, 가운데 세로 판 + 양옆 패널 배치
5. **과일 맞추기**: 매치 판정, 떨어뜨리기·연쇄
6. **공 쏘기 벽돌깨기**: 조준선, 공 여러 개(벽돌깨기 그림·충돌 재사용)
7. **방울 쏘기**: 어긋난 격자, 조준선 재사용
8. **블록 쌓기**: 낙하 블록, 터치 조작 버튼
9. **그림 스도쿠**: 문제 생성기(답 하나뿐 검사), 힌트·메모
10. **네모 나누기**: 끌어서 네모 그리기, 문제 생성기
11. **상자 밀기**: 미로 탈출 판·방향 입력 재사용, 되돌리기
12. **하늘 비행 모험**: 등장 표, 방울 패턴, 대장(가장 큼)


## AI 구현 시 권장 방식

한 번에 전체 프로젝트를 생성하도록 요청하기보다 아래 순서로 AI에게 작업을 맡기는 것이 좋다.

```text
1. 프로젝트 기본 구조 생성
2. 메인 메뉴 생성
3. 풍선 터뜨리기 단독 구현
4. 플레이 테스트 및 버그 수정
5. 공통 UI / AudioManager 분리
6. 과일 받기 추가
7. 나머지 게임을 하나씩 추가
8. 기록 저장 시스템 연결
9. 모바일 터치 대응
10. 최종 UI / 사운드 / 애니메이션 개선
```

각 미니게임이 독립적인 Scene을 사용하고, 공통 데이터와 설정만 공유하도록 구성하면 관리하기 쉽다.
