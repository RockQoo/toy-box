# 풍선 터뜨리기 개선 사항

기획서: [../games/01-balloon-pop.md](../games/01-balloon-pop.md) · 코드: `scripts/Games/Balloon/`

## P1

- [ ] **B-1 "그만하기"를 실수로 누르기 쉬움**
  - 문제: 왼쪽 아래에 있어서 풍선을 누르다가 잘못 누르기 쉽고, 누르는 즉시 게임이 끝난다.
  - 위치: `BalloonGame.cs` `BuildHud`
  - 제안: 위쪽 점수판 옆으로 옮기고, "정말 그만할까요?" 확인을 한 번 거친다.
  - 출처: 2026-10-17 polish-review

## P2

- [ ] **B-2 속도 선택이 글자로만 되어 있음**
  - 위치: `BalloonGame.cs` `SpeedChoices`
  - 제안: 이미 있는 그림을 붙인다(느림: 거북이 `animal/turtle.png`, 빠름: 토끼 `animal/rabbit.png`, 보통: 펭귄 등).

- [ ] **B-3 터지는 효과가 약해 보임**
  - 문제: 펑 그림이 풍선 크기보다 작아서 약해 보인다.
  - 위치: `BalloonGame.cs` `SpawnPopEffect`
  - 제안: 펑 그림을 1.3배로 키우고 풍선 색 고무 조각을 몇 개 추가한다. 자주 일어나는 행동이므로 화면 흔들림은 넣지 않는다.

- [ ] **B-4 점수판 아이콘이 항상 빨간 풍선**
  - 위치: `BalloonGame.cs` `BuildHud`
  - 제안: 고른 풍선 색을 반영한다(랜덤이면 마지막으로 터뜨린 색).

- [ ] **B-5 결과 화면을 닫는 코드가 두 군데에 중복됨**
  - 위치: `BalloonGame.cs` `StartRound`, `ShowResult`의 "꾸미기" 버튼
  - 제안: `CloseResult()` 하나로 합친다.

- [ ] **B-6 남은 시간 막대** → 공통 항목 [C-3](common.md)으로 진행

## P3

- [ ] **B-7 배경 선택이 단색 네모로만 보임** `리소스 필요`
  - 위치: `Scenery.Choices`
  - 제안: 우주·바다·하늘 배경 이미지가 생기면 작은 미리보기 그림으로 바꾼다.

- [ ] **B-8 응원 친구가 카드 그림이라 스티커처럼 보임** `리소스 필요`
  - 위치: `Buddy.Choices`
  - 제안: 투명 배경 캐릭터(기본, 점프, 환호 포즈)가 생기면 바꾼다. 기획서 예시의 고양이도 추가한다.

## 잘 되어 있어서 유지할 것

카운트다운, 마지막 5초 경고(주황색과 똑딱 소리), "끝!" 표시와 풍선이 날아가는 마무리, 결과 숫자 올라가기, 최고 기록 축하(팡파르와 색종이), 랭킹 강조, 빈 곳을 눌렀을 때의 물결 표시.
