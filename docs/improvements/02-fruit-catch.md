# 과일 받기 개선 사항

기획서: [../games/02-fruit-catch.md](../games/02-fruit-catch.md) · 코드: `scripts/Games/Fruit/`

첫 구현(2026-10-17) 직후의 자체 검토 결과다. 자동 플레이 프레임으로 확인했고, 실제 터치 기기와 마우스로는 아직 해 보지 않았다.

## P1

- [ ] **F-1 실제 기기에서 조작감 확인**
  - 문제: 바구니가 손가락/마우스 x를 따라가는 동작(`InputEventScreenTouch`/`ScreenDrag`/`MouseMotion`)과 ← → / A D 키는 코드로만 확인했다. 창 포커스를 빼앗는 대화형 테스트는 하지 않았다.
  - 위치: `FruitGame.cs` `_UnhandledInput`, `MoveBasket`
  - 제안: PC(마우스만 움직이기, 클릭 드래그, 키보드)와 안드로이드(드래그)에서 한 판씩 해 보고, 따라가는 빠르기(`Basket.FollowRate`)와 키 속도(`KeySpeed`)를 조정한다.

## P2

- [ ] **F-2 응원 친구가 바구니에 가려짐**
  - 문제: 친구가 오른쪽 아래에 서 있어서 바구니가 오른쪽 끝으로 가면 친구를 덮는다(바구니가 앞). 꾸미기 화면에서는 바구니를 친구 왼쪽에 두도록 막았지만 플레이 중에는 겹친다.
  - 위치: `FruitGame.cs` `Layout`
  - 제안: 플레이 중에는 친구를 조금 위(언덕 위 등)로 올리거나, 바구니가 겹치면 친구를 살짝 비켜 서게 한다. 투명 배경 캐릭터(B-8)가 생기면 함께 정한다.

- [ ] **F-3 과일이 점수판·시간판 뒤에서 생겨 잠깐 안 보임**
  - 문제: 과일은 화면 맨 위 바로 위에서 생기는데, 왼쪽 위 점수판과 오른쪽 위 시간판 아래를 지나는 동안 가려진다.
  - 위치: `FruitGame.cs` `SpawnRoundFruit`
  - 제안: 점수판·시간판 아래에서는 덜 생기게 하거나, HUD 아래 높이에서 살짝 커지며 나타나게 한다.

- [ ] **F-4 꾸미기 화면의 미리보기 바구니가 16:9에서는 움직이지 않음**
  - 문제: 다섯 줄 패널 오른쪽 빈 곳이 바구니 폭 정도라, 1280x720에서는 바구니가 제자리에서 과일을 받기만 한다(더 넓은 화면에서는 움직인다).
  - 위치: `FruitGame.cs` `BasketRange`
  - 제안: 패널 칩을 조금 줄이거나, 미리보기 동안 바구니를 약간 작게 보여 준다.

- [ ] **F-5 속도 그림(펭귄·토끼)이 응원 친구 줄과 같음** → 풍선 [B-9](01-balloon-pop.md)와 같은 문제(공통 `Choice.Speeds`). 함께 고친다.

## P3

- [ ] **F-6 받은 과일이 바구니에 쌓여 보이기**
  - 제안: 마지막으로 받은 과일 몇 개를 바구니 입구 위로 살짝 보이게 해서, 많이 받을수록 바구니가 차오르는 느낌을 준다.

- [ ] **F-7 황금 과일이 동전 그림** `리소스 필요`
  - 제안: 황금 사과 그림이 생기면 `Fruit.BonusTexture`를 바꾼다.

- [ ] **F-8 바구니 모양 선택** `리소스 필요`
  - 제안: 다른 모양 바구니 그림이 생기면 색 선택(셰이더)을 모양 선택으로 바꾸거나 함께 쓴다.

- [ ] **F-9 연속으로 받기를 화면에도 표시** → 공통 [C-4](common.md)

## 잘 되어 있어서 유지할 것

과일이 바구니 앞에서 떨어지다 받으면 뒤로 쏙 들어가는 것, 받기/황금 과일/10개 단위의 연출 크기 차이, 바닥에 떨어져도 감점이나 실패음이 없는 것, 꾸미기 화면에서 고른 과일과 바구니 색이 바로 보이는 미리보기.
