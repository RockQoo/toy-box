# 공통 시스템 개선 사항

## P1

- [ ] **C-1 다시 하기 후 음악이 작고 빨라진 채로 남음 (버그)**
  - 문제: 결과 화면에서 낮춘 음량(`DuckMusic`)과 마지막 단계에서 올린 템포(`SetMusicTempo`)가 다음 판에 되돌아가지 않는다. `PlayMusic`은 같은 곡이면 바로 반환하기 때문이다.
  - 위치: `scripts/Common/Audio.cs` `PlayMusic`, `DuckMusic`, `SetMusicTempo`
  - 제안: 같은 곡이어도 음량과 템포를 기본값으로 되돌리는 `ResetMusic()`을 두고, 게임이 판을 시작할 때 부른다.
  - 출처: 2026-10-17 polish-review (풍선 터뜨리기)

- [ ] **C-2 Top 10에 들 때마다 이름을 키보드로 입력해야 함**
  - 문제: 기록이 10개 찰 때까지는 매 판 입력창이 뜬다. 글을 못 쓰는 아이에게는 진입 장벽이다.
  - 위치: `scripts/Common/Ui/ResultPanel.cs` `BuildNameEntry`, `RunSequence`
  - 제안: 최근에 쓴 이름 2~3개를 큰 버튼으로 보여 주고, 한 번 누르면 등록되게 한다. 키보드 입력은 "새 이름" 버튼 뒤로 둔다. 최근 이름 목록은 `App` 설정에 저장한다.
  - 출처: 2026-10-17 polish-review
