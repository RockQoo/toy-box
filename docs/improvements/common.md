- [x] **C-5 이름 입력에서 한글 이름이 한 글자만 저장됨 (버그)** — 완료 2026-10-17
  - 문제: "랭킹 입력 시 한 글자밖에 못 넣는다"(사용자 제보). 한글 IME로 "다온"을 치면 마지막 글자 "온"은 아직 조합 중이라 `LineEdit.Text`에 들어가 있지 않다. "확인" 버튼은 포커스를 가져가지 않으므로 조합이 끝나지 않은 채 `Text`를 읽어 "다"만 저장됐다(두 글자 이름이면 한 글자). 그 뒤 `ReleaseFocus`에서야 조합 글자가 들어갔다. 기록에 남은 "나"도 이렇게 잘린 이름일 수 있다. 영문은 조합이 없어서 문제가 없었다(헤드리스에서 키 입력으로 확인).
  - 위치: `scripts/Common/Ui/ResultPanel.cs` `SubmitTyped`, `SubmitName`
  - 완료: 제출할 때 두 프레임 기다려(Enter로 확정된 글자가 먼저 들어오게) `LineEdit.ApplyIme()`로 조합 중인 글자를 확정한 뒤 읽는다. `SelectAllOnFocus`와 미리 채운 이름을 없애고(빈 칸에서 시작, 커서는 끝) 입력 칸에 포커스를 주는 것은 레이아웃 뒤로 미뤘다. 한글 IME는 헤드리스로 재현할 수 없어 실제 키보드로 확인이 필요하다.
  - 출처: 2026-10-17 사용자 제보
