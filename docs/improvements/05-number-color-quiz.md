# 숫자 / 색깔 퀴즈 개선 사항

기획서: [../games/05-number-color-quiz.md](../games/05-number-color-quiz.md) · 코드: `scripts/Games/Quiz/`, `scripts/Core/QuizRules.cs`

첫 구현(2026-10-17) 직후의 자체 검토 결과다. 자동 플레이 프레임(색깔·보통, 숫자·어려움, 섞어서·쉬움)으로 확인했고, 실제 터치 기기와 마우스로는 아직 해 보지 않았다.

## P1

- [ ] **Q-1 실제 기기에서 아이와 한 판 해 보기**
  - 문제: 카드 누르기, 오답 흔들림, 정답 연출의 길이(약 1.1초 + 등장 0.6초)는 자동 플레이로만 봤다. 아이가 기다리기에 긴지 짧은지, "한 번 더 찾아볼까요?"를 이해하는지 확인하지 않았다.
  - 위치: `QuizGame.cs` `RightPick`(`FeedbackPause`), `NextQuestion`
  - 제안: 한두 판 해 보고 쉼 시간을 조정한다. 오답 뒤 다시 고르기 전에 망설이면 예시 그림을 한 번 더 튀게 하는 것도 검토.

## P2

- [ ] **Q-2 문제를 소리로 읽어 주지 않음** `리소스 필요`
  - 문제: 글을 못 읽는 아이는 예시 그림과 "띵동" 소리로만 문제를 알아챈다. 숫자 문제는 예시 숫자를 보고 같은 모양을 찾는 것이라 숫자 이름(삼, 셋)은 배우지 못한다.
  - 위치: `QuizGame.cs` `NextQuestion`
  - 제안: "빨간색", "숫자 3" 같은 녹음 음성(또는 TTS)을 받으면 문제가 나올 때 재생하고, 예시 그림을 누르면 다시 들려준다.

- [ ] **Q-3 결과 화면에 걸린 시간이 바로 보이지 않음**
  - 문제: 시간은 같은 개수일 때 순위를 가르는 값인데, 결과 왼쪽에는 맞힌 개수와 별만 나온다. Top 10에 들면 순위표 줄에서 보이지만 못 들면 알 수 없다.
  - 위치: `QuizGame.cs` `ShowResult`, `ResultPanel`
  - 제안: 별 줄 옆이나 아래에 작게 "12.3초"를 보여 준다(아이에게는 중요하지 않아 작게).

- [ ] **Q-4 정답 뒤 문장 판 위치가 문장 길이에 따라 바뀜**
  - 문제: 문장 판은 문장 길이에 맞춰 커지고 작아지며 가운데 정렬이라, 문제가 바뀔 때마다 예시 그림 위치가 조금씩 움직인다.
  - 위치: `QuizGame.cs` `BuildPlayUi`
  - 제안: 문장 판 최소 폭을 가장 긴 문장에 맞춰 고정한다.

## P3

- [ ] **Q-5 숫자 6~9 카드 그림** `리소스 필요`
  - 문제: 6~9는 코드로 그려서 1~5 그림보다 광택과 입체감이 덜하다.
  - 위치: `QuizCard.cs` `DrawNumberCard`
  - 제안: `num_6.png`~`num_9.png`를 받으면 넣고 `PaintedNumbers`를 9로 바꾼다(`docs/resources.md`).

- [ ] **Q-6 개수 찾기 / 같은 그림 찾기 문제**
  - 문제: 기획서의 확장 문제 종류는 초기 범위 밖이라 만들지 않았다.
  - 위치: `QuizRules.cs` `QuizKind`, `QuizCard.cs`
  - 제안: 개수 찾기는 과일 그림(`fruit/`)을 카드 안에 1~5개 그려서 만들 수 있다. 같은 그림 찾기는 동물 카드(`animal/`)로 가능. 새 종류도 난이도별 랭킹은 그대로 쓴다.
