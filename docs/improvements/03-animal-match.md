# 동물 짝 맞추기 개선 사항

기획서: [../games/03-animal-match.md](../games/03-animal-match.md) · 코드: `scripts/Games/Memory/`, `scripts/Core/MemoryRules.cs`

첫 구현(2026-10-17) 직후의 자체 검토 결과다. 자동 플레이 프레임(쉬움·보통·어려움)으로 확인했고, 실제 터치 기기와 마우스로는 아직 해 보지 않았다.

## P1

- [ ] **A-1 실제 기기에서 아이와 한 판 해 보기**
  - 문제: 공개 시간(2초), 짝 실패 뒤 보여 주는 시간(1초), 뒤집기 속도는 자동 플레이로만 봤다. 어린 아이에게 2초 공개가 짧은지, 실패 뒤 1초가 기억하기에 충분한지 확인하지 않았다.
  - 위치: `MemoryRules.RevealSeconds`, `MemoryRules.MismatchSeconds`, `MemoryCard.Turn`
  - 제안: 한두 판 해 보고 조정한다. 쉬움만 공개 시간을 늘리는 것도 검토.

## P2

- [ ] **A-2 개구리와 거북이가 비슷해 보임**
  - 문제: 두 카드 모두 초록색 동물에 비슷한 색 바탕이라, 작은 아이는 공개 때나 쌍 칸에서 헷갈릴 수 있다. 쉬움(3쌍)에서 둘이 함께 나오면 난이도가 갑자기 올라간다.
  - 위치: `MemoryRules.Deal`
  - 제안: 쉬움에서는 개구리와 거북이를 함께 고르지 않는다(보통 이상은 그대로).

- [ ] **A-3 동물 이름을 소리로 들려주지 않음** `리소스 필요`
  - 문제: 짝을 찾으면 이름이 글자로만 떠오른다. 글을 못 읽는 아이에게는 종소리만 전달된다.
  - 위치: `MemoryGame.cs` `Matched`
  - 제안: 동물 이름 녹음(또는 울음소리)을 받으면 짝 성공 때 재생한다.

- [ ] **A-4 짝 실패 뒤 다시 뒤집히기 전에 다른 카드를 눌러도 반응 없음**
  - 문제: 기획서대로 비교 중에는 입력을 잠그는데, 아이가 1초를 못 기다리고 누르면 아무 반응이 없어 고장처럼 느낄 수 있다.
  - 위치: `MemoryGame.cs` `OnCardPressed`
  - 제안: 잠긴 동안 누른 카드는 살짝 흔들리거나, 누르면 바로 두 카드를 뒤집고 그 카드를 첫 카드로 여는 방식을 검토한다.

## P3

- [ ] **A-5 쌍 칸으로 날아가는 연출**
  - 문제: 쌍 칸은 그 자리에서 튀며 채워지기만 해서, 카드와 칸의 연결이 약하다.
  - 위치: `MemoryGame.cs` `FillSlot`
  - 제안: 퀴즈의 별처럼 작은 동물 그림이 카드에서 칸으로 날아가 박히게 한다.

- [ ] **A-6 결과 화면에 별 평가 없음**
  - 문제: 시간과 뒤집은 횟수만 나와서 아이가 잘했는지 한눈에 알기 어렵다.
  - 위치: `MemoryGame.cs` `ShowResult`
  - 제안: 뒤집은 횟수가 최소(쌍 수 x 2)에 가까울수록 별 1~3개(`ResultSpec.StarsTotal`)를 보여 준다.
