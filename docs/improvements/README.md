# 개선 사항 목록

연출/완성도 검토(`/polish-review`)와 플레이 테스트에서 나온 개선 사항을 범위별로 모아 둔다.
게임을 추가하면 `NN-<id>.md`(기획서 `docs/games/`와 같은 이름)를 새로 만든다.

| 파일 | 범위 |
|---|---|
| [common.md](common.md) | 여러 게임이 함께 쓰는 시스템(오디오, 결과 화면, 랭킹, UI) |
| [main-menu.md](main-menu.md) | 메인 메뉴, 기록·설정 화면 |
| [01-balloon-pop.md](01-balloon-pop.md) | 풍선 터뜨리기 |
| [02-fruit-catch.md](02-fruit-catch.md) | 과일 받기 |
| [03-animal-match.md](03-animal-match.md) | 동물 짝 맞추기 |
| [05-number-color-quiz.md](05-number-color-quiz.md) | 숫자 / 색깔 퀴즈 |

## 작성 규칙

- 항목마다 ID를 붙인다: 공통 `C-`, 메뉴 `M-`, 게임은 게임 id 약자(풍선 `B-`, 과일 `F-`, 짝 맞추기 `A-`, 퀴즈 `Q-`). 번호는 재사용하지 않는다.
- 우선순위: **P1** 바로 고치면 효과가 큰 것 / **P2** 적은 비용으로 개선 / **P3** 나중에 다듬을 디테일.
- 체크박스로 상태를 표시한다. 끝내면 `[x]`로 바꾸고 완료일을 적는다. 하지 않기로 하면 `~~취소선~~`과 이유를 남긴다.
- 위치는 `파일:줄` 대신 `파일` + 함수/메서드 이름으로 적는다(줄 번호는 금방 바뀐다).
- 리소스가 필요해서 막힌 항목은 `리소스 필요` 표시를 붙인다.
