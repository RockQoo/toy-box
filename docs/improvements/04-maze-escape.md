# 미로 탈출 개선 사항

기획서: [../games/04-maze-escape.md](../games/04-maze-escape.md) · 코드: `scripts/Games/Maze/`, `scripts/Core/MazeRules.cs`

첫 구현(2026-10-17) 직후의 자체 검토 결과다. 자동 플레이 프레임(쉬움·보통·어려움, 1280x720)으로 확인했고, 실제 터치 기기와 키보드로는 아직 해 보지 않았다.

## P1

- [ ] **MZ-1 실제 기기에서 아이와 한 판 해 보기**
  - 문제: 한 칸 이동 시간(0.14초), 누르고 있을 때 반복 간격(0.3초 뒤 0.19초마다), 스와이프 거리(칸의 60%), 방향 버튼 크기(118px)는 자동 플레이로만 봤다. 어린 아이가 버튼을 누르고 있다가 갈림길을 지나쳐 버리는지, 스와이프가 너무 민감한지 확인하지 않았다.
  - 위치: `MazeGame.cs` 상수 `StepTime`, `RepeatDelay`, `RepeatEvery`, `_UnhandledInput`(스와이프), `PadButton`
  - 제안: 한두 판 해 보고 조정한다. 누르고 있을 때 갈림길에서 한 번 멈추는 방식도 검토.

## P2

- [ ] **MZ-2 결과 화면에서 난이도를 바꾸려면 메인으로 나가야 함**
  - 문제: 결과 버튼이 기획서대로 다음 미로 / 다시 하기 / 메인으로 3개라, 다른 난이도를 하려면 메뉴로 나가 다시 들어와야 한다.
  - 위치: `MazeGame.cs` `ShowResult`
  - 제안: 어려움의 마지막 미로까지 하면 "다음 미로" 대신 "난이도 고르기"를 보여 주거나(짝 맞추기 방식), "메인으로" 대신 꾸미기 화면으로 가는 버튼을 둔다.

- [ ] **MZ-3 캐릭터가 카드 그림이라 미로 안에서 스티커처럼 보임** `리소스 필요`
  - 문제: 캐릭터는 응원 친구와 같은 동물 카드 그림(분홍·초록 바탕 테두리)이라 미로 위에서 말판처럼 보이고, 왼쪽으로 갈 때 카드째 뒤집힌다.
  - 위치: `MazePlayer.cs` `SetCharacter`, `StepTo`
  - 제안: 투명 배경 캐릭터(개선 B-8, `docs/resources.md`)를 받으면 바꾼다.

- [ ] **MZ-4 같은 난이도의 미로 5개가 한 순위표를 같이 씀**
  - 문제: 미로마다 최단 경로 길이가 다르다(어려움 26~34걸음). 짧은 미로에서 세운 기록이 긴 미로에서는 깨기 어렵다.
  - 위치: `MazeGame.cs` `ShowResult`(`VariantId`), `MazeRules.Seeds`
  - 제안: 순위표는 그대로 두고 꾸미기 화면 미리보기 아래에 "이 미로 최고 기록"을 따로 보여 주거나, 난이도 안에서 최단 경로 길이가 비슷한 시드만 고른다.

## P3

- [ ] **MZ-5 벽·바닥·출구 그림** `리소스 필요`
  - 문제: 코드로 그린 울타리와 깃발이라 배경 그림(공원)에 비해 단순하다.
  - 위치: `MazeBoard._Draw`, `MazeExit._Draw`
  - 제안: 타일 그림을 받으면 바꾼다(`docs/resources.md`).

- [ ] **MZ-6 오래 멈춰 있으면 길 힌트**
  - 문제: 어려움에서 길을 못 찾으면 도움이 없다.
  - 위치: `MazeGame.cs` `_Process`
  - 제안: 10초쯤 움직이지 않으면 출구 깃발이 뛰거나 다음 갈림길 방향이 잠깐 반짝인다.

- [ ] **MZ-7 무작위 미로**(기획서의 확장 기능)
  - 문제: 난이도마다 미로 5개를 돌아가며 하므로 많이 하면 외운다.
  - 위치: `MazeRules.Get`, `MazeGenerator`
  - 제안: 생성기와 조건 검사(테스트에 있는 것)를 그대로 써서, 조건을 만족하는 시드를 실행 중에 골라 "새 미로"를 만든다. 순위는 그대로 난이도별.
