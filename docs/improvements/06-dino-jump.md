# 공룡 점프 개선 사항

기획서: [../games/06-dino-jump.md](../games/06-dino-jump.md) · 코드: `scripts/Games/Dino/`, `scripts/Core/DinoRules.cs`

첫 구현(2026-10-17) 직후의 자체 검토 결과다. 자동 플레이 프레임(1280x720, 꾸미기 → 달리기 → 속도 단계 → 넘어짐 → 결과)으로 확인했고, 실제 터치 기기와 키보드로는 아직 해 보지 않았다.

## P1

- [ ] **D-1 실제 기기에서 아이와 한 판 해 보기**
  - 문제: 달리는 속도(화면 높이 0.55/초), 점프(높이 0.40, 0.75초), 충돌 상자 크기, 점프 버퍼(0.15초), 늦은 점프 유예(0.08초), 장애물 간격은 단위 테스트와 자동 플레이로만 맞췄다. 어린 아이가 너무 일찍 누르는지(버퍼가 더 길어야 하는지), 첫 장애물까지 기다리는 시간이 긴지 확인하지 않았다.
  - 위치: `DinoRules` 상수(`BaseRunSpeed`, `JumpHeight`, `JumpDuration`, `JumpBuffer`, `CrashGrace`, `Reaction`), `NextGap`
  - 제안: 한두 판 해 보고 조정한다. 값을 바꾸면 `DinoRulesTests`(모든 속도에서 넘을 수 있는지, 최소 간격)가 함께 확인한다.

## P2

- [ ] **D-2 넘어진 뒤 결과 화면까지 기다려야 함**
  - 문제: 넘어지고 2초 뒤 결과 화면이 나오고, 결과 화면도 count-up과 이름 입력을 거친다. 바로 다시 하고 싶은 아이에게는 길 수 있다.
  - 위치: `DinoGame.Crash`, `ShowResult`
  - 제안: "앗! 다시 해볼까요?"가 나온 뒤 화면을 누르면 바로 결과 화면으로 넘어가게 한다. 0점일 때는 결과 화면 대신 "다시 하기" 버튼을 바로 보여 주는 것도 검토.

- [ ] **D-3 넘어지는 포즈가 엎드린 그림** `리소스 필요`
  - 문제: 넘어지는 그림이 없어 점프 그림으로 구르다가 엎드린 그림(`dino_crouch.png`)으로 바꾼다. 아파 보이지 않아 좋지만 "넘어졌다"는 느낌은 약하다.
  - 위치: `Dino.Tumble`
  - 제안: 엉덩방아 찧는 포즈를 받으면 바꾼다(`docs/resources.md`).

- [ ] **D-4 공룡 색이 셰이더 색 바꾸기뿐** `리소스 필요`
  - 문제: 다섯 가지 색이 모두 같은 그림이고, 노랑은 그림자 부분이 올리브색에 가깝다.
  - 위치: `Dino.HueShifts`, `Dino.MaterialFor`
  - 제안: 다른 공룡 그림(트리케라톱스 등)을 받으면 모양 선택으로 바꾼다.

- [ ] **D-5 땅 타일 이음매가 보임**
  - 문제: `ground.png` 양 끝이 둥글고 테두리가 있어서 이어 붙이면 블록 사이에 홈이 보인다(블록 길처럼 보여 크게 어색하지는 않다).
  - 위치: `Landscape.DrawGround`
  - 제안: 이어 붙일 수 있는 땅 그림을 받거나, 그림 가운데 부분만 잘라 반복한다.

## P3

- [ ] **D-6 좁은 화면비(4:3 태블릿)에서 장애물이 보이는 시간이 짧음**
  - 문제: 거리 단위가 화면 높이라 화면이 좁으면 장애물이 나타나서 공룡까지 오는 시간이 짧아진다(16:9 약 2.6초, 4:3 약 1.8초, 보통 속도 처음).
  - 위치: `DinoGame.PlayX`, `SpawnObstacle`
  - 제안: 좁은 화면에서는 공룡을 더 왼쪽에 두거나 처음 속도를 조금 낮춘다.

- [ ] **D-7 알·별 모으기**(기획서 확장)
  - 문제: 넘기만 하므로 단조로울 수 있다. `egg.png`가 있지만 쓰지 않았다.
  - 위치: `DinoGame.UpdatePlaying`
  - 제안: 점프해야 닿는 높이에 알을 가끔 띄우고, 먹으면 +1과 반짝임. 장애물 간격 규칙(`MinGap`)을 깨지 않게 장애물 사이에만 둔다.

- [ ] **D-8 익룡 장애물과 엎드리기**(기획서 확장)
  - 문제: 익룡은 배경 장식이다. 엎드리기는 두 번째 버튼(또는 아래로 밀기)이 필요해 한 버튼 원칙과 맞지 않는다.
  - 위치: `DinoGame.StepPteros`
  - 제안: 하려면 "높이 나는 익룡 아래를 그냥 달려 지나가기"처럼 한 버튼으로 되는 변형만 검토한다.

- [ ] **D-9 효과음 파일** `리소스 필요`
  - 문제: 점프 "보잉", 통과 "띵", 넘어짐 "뿌우웅"이 합성음이다.
  - 위치: `SfxSynth.Jump`, `PassTick`, `Tumble`
  - 제안: 공통 효과음 리소스(`docs/resources.md`)를 받을 때 함께 바꾼다.
