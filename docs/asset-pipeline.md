# 리소스 제작 노하우 & 작업 일지

그림(ChatGPT 이미지)과 소리(Kenney / Pixabay)를 구해서 게임에 넣는 방법과, 해 보면서 알게 된 것을 모은다.
다른 프로젝트에서도 쓰도록 같은 내용을 일반화한 스킬이 `~/.claude/skills/game-asset-pipeline/`에 있다.

## 그림: ChatGPT에 요청하기

### 잘 된 방법
- **기존 그림을 반드시 첨부**한다(`art-source/sheet_*.png`, `bg_sky.png`). "첨부 그림과 똑같은 그림체"가 기준이 된다. 첨부가 없으면 그림체가 매번 달라진다.
- **시트 0(스타일 기준표)을 먼저** 만들게 해서 확인한 뒤 진행한다. 이번에는 토끼 한 마리로 확정했고, 이후 동물들이 모두 같은 그림체로 나왔다.
- **시트 하나씩** 요청한다. 한 번에 여러 시트를 시키면 시트끼리 크기와 그림체가 흔들린다.
- 시트마다 **파일 이름 목록**을 주고, 그 순서대로 격자에 배치하게 한다. 자를 때 순서대로 이름을 붙이면 된다.
- 규칙은 맨 앞에 한 번만 길게 쓰고, 이후 요청은 "시트 N 만들어 줘"처럼 짧게 한다. 대화가 길어져 그림체가 흐트러지면 새 대화에 프롬프트 + 기준 그림 + 확정된 시트 0을 다시 붙인다.
- 아이용 규칙(빨간 경고·해골·부서짐·우는 얼굴 금지, 실수는 "깜짝/어지러움")과 "그림에 글자 넣지 않기"를 공통 규칙에 넣는다.

### 한 번에 다 만들어 달라고 하면 안 되는 이유
- ChatGPT 이미지 크게 보기 화면에서는 투명 부분으로 뒤 화면(사이드바 대화 목록)이 흐리게 비친다. 그림에 들어간 게 아니라 투명이라는 뜻이니 받은 파일로 확인한다. 다만 그 스크린샷은 대화 제목이 보이니 공유하지 않는다.
- ChatGPT는 한 답변에 여러 장을 만들 수 있지만(처음 요청 때 시트 5장이 한 번에 나옴) 한 답변의 작업량에 한도가 있는 듯하다. 남은 시트 20장 이상을 한꺼번에 시키자 몇 장 만들고 멈췄고, 이유를 물으면 "제가 끊었다"고 사과만 했다. 사용량 제한도 있다.
- 그래서 **4~5장씩 묶어서** 요청하고(예: "시트 19, 23, 26, 27 만들어 줘"), 끝나면 **"지금까지 만든 이미지 전부 zip으로 묶어 줘"**로 한 번에 받는다.
- ChatGPT 캔버스의 회색 체크무늬는 투명 표시일 수 있다. 받은 뒤 알파로 확인한다.

### 복붙이 안 될 때
- 긴 글은 ChatGPT가 "붙여 넣은 텍스트" 파일 칩으로 바꾼다. 그대로 보내면 된다.
- "이미지 만들기" 도구를 켠 상태에서는 길이 제한에 걸릴 수 있다. 일반 대화에서 붙여 넣는다. 그래도 안 되면 md 파일을 첨부한다.

### ChatGPT가 자주 틀린 것 (다음엔 프롬프트에 미리 적기)
| 문제 | 예 | 프롬프트에 넣을 문장 |
|---|---|---|
| 그림 간격이 너무 좁음 | 시트 1 위아래 줄 사이 1px | "줄과 그림 사이 간격을 그림 높이의 1/4 이상" |
| 오버레이를 불투명 타일로 그림 | Match-3 가로줄/세로줄/폭탄 | "바탕 타일 없이 빛줄기만, 투명 배경 오버레이" |
| 단계 색이 반복됨 | 2048 타일 1~4와 5~8이 같은 색 순서 | "12단계 모두 다른 색, 같은 색 계열 금지" |
| 칸 단위 조각이 길게 나옴 | 애벌레 몸통이 마디 3개 | "각 조각이 정사각형 한 칸에 딱 맞게, 몸통은 마디 1개" |
| 타일 가장자리가 울퉁불퉁/테두리 있음 | 잔디 타일, 미로 바닥 | "테두리 없이 가장자리까지 꽉 찬 정사각형, 이어 붙여도 이음매 없게" |
| 물건 방향이 틀림 | 뒤집은 밀짚모자를 바로 세워 그림 | "입구가 위를 향해 과일을 받을 수 있게"처럼 쓰임새로 설명 |
| 비슷한 것과 구분이 안 됨 | 양동이를 바구니처럼 그림 | "기존 바구니와 다르게, 손잡이 달린 플라스틱 양동이" |
| 포즈 구분이 약함 | 점프와 환호가 둘 다 팔 들기 | "점프는 두 발이 확실히 공중에" |
| 그림 안에 소품이 붙음 | 던지기 포즈에 공이 그려짐 | 색이 바뀌는 소품은 "손만, 소품 없이" |
| 그림체가 3D 렌더링으로 바뀜 | 방울 쏘기 시트(외곽선 없는 플라스틱 질감) | "처음 첨부한 그림처럼 진한 남색 외곽선 만화풍, 3D 렌더링 금지" |
| 물건 밑에 그림자 | 방울 쏘기 시트(흰 타원 그림자) | "바닥 그림자 넣지 마, 투명 배경에 물건만" |
| 애니메이션 프레임이 다 같음 | 터짐 4프레임이 같은 사각 틀 4개 | 프레임마다 모양을 하나씩 설명 |
| 받침에 내용물을 같이 그림 | 다음 방울 받침에 방울 4개 | "받침만, 내용물 없이" |
| 회전하는 부품이 몸체에 붙어 고정 각도로 나옴 | 방울 쏘기 대포 포신이 기울어진 채 받침대와 한 그림 | "받침대와 포신을 따로, 포신은 똑바로 위를 향하게, 아래 끝에 회전 축" |
| 원하는 크기보다 작음 | 배경 1672×941 | 1280×720 기준이면 충분. 1080p는 살짝 확대됨 |

### 검수 체크리스트
1. **그림체**: 기준 그림(시트 0)과 선 굵기·눈·명암이 같은가.
2. **투명 배경**: PNG 색 형식이 6(RGBA)인지(`od -An -tu1 -j16 -N10 파일`의 마지막 값), 모서리 픽셀 알파가 0인지. **배경이 회색/남색으로 보여도 알파가 0이면 정상**이다(투명 픽셀 아래 남은 색일 뿐). 반대로 체크무늬가 그림으로 그려진 경우는 불투명이라 다시 받는다.
3. **자를 수 있는지**: `cut.ps1` 미리보기로 그림 개수와 상자가 맞는지. 두 그림이 한 상자로 붙으면 다시 받거나 그 부분만 버린다.
4. **빠진 것**: 프롬프트 목록과 비교.
5. **규칙 위반**: 글자, 빨간 경고, 아파 보이는 표현.
6. **기존 그림과 크기 비율**: 예) 숫자 카드 6~9가 1~5보다 넓음 → 자를 때 축소 비율로 높이를 맞춘다.

## 그림: 자르기와 넣기

```bash
S=<스크래치 폴더>   # 미리보기 그림은 프로젝트 밖에
# 1) 미리보기: 그림마다 번호와 상자 출력(+ 빨간 상자 그림)
powershell -NoProfile -ExecutionPolicy Bypass -File tools/asset/cut.ps1 -Sheet <시트.png> -Preview $S/prev.png
# 2) 내보내기: 번호 순서대로 이름(쉼표 구분, "-"는 건너뜀), 축소 비율
powershell -NoProfile -ExecutionPolicy Bypass -File tools/asset/cut.ps1 -Sheet <시트.png> -Mode export \
  -OutDir <절대경로>/assets/sprites -Scale 0.6 -Names "buddy/rabbit_idle,buddy/rabbit_jump,-,..."
# 3) 확인: 잘린 파일을 한 장에 모아 보기
powershell -NoProfile -ExecutionPolicy Bypass -Command "& 'tools/asset/montage.ps1' -Out '$S/m.png' -Files (...)"
# 4) Godot import
Godot_v4.7.2-stable_mono_win64_console.exe --headless --path . --import
```

- `cut.ps1`은 알파 40 초과 픽셀로 8방향 연결 영역을 찾고, 가장 큰 영역의 `MinFrac`(기본 2%)보다 작은 조각은 `MergeDist`(기본 40px) 안의 큰 그림에 붙인다(어지러움 별, 반짝이). 물감 튀김처럼 조각이 큰 그림은 `-MinFrac 0.1 -MergeDist 80`.
- 조각이 흩어진 그림(반짝이, 별 조각 프레임)은 자동으로 한 장이 안 된다 → `-Rects "x0,y0,x1,y1;..."`로 영역을 지정하면 중심이 그 안에 있는 조각을 모두 한 그림으로 묶는다(미리보기 번호 대신 영역 순서대로 이름).
- **그림 테두리끼리 맞닿은 시트**(스도쿠 얼굴 줄)는 연결 영역이 하나로 잡힌다. `-Alpha 150`(흐린 빛 번짐으로만 붙은 경우)으로 먼저 시도하고, 그래도 붙으면 `-Seeds "x,y;..."`로 그림마다 안쪽 점을 하나씩 찍는다(동시에 퍼져 먼저 닿은 쪽으로 나눔, 이름은 점 순서).
- 이어 붙일 타일이 좌우·상하 끝에서 완전히 맞물리지 않으면(ChatGPT 타일은 대부분 그렇다) Godot에서 **거울 반복**(`TextureRepeat` Mirror)으로 깐다. 다시 요청하는 것보다 빠르다.
- 줄 정렬은 중심 y가 같은 줄(높이의 절반 이내)끼리 묶고 왼쪽부터. 시트 배치가 어긋나면 미리보기 번호를 보고 이름 순서를 맞춘다.
- 축소 비율은 **기존 그림 크기에 맞춘다**(캐릭터·과일 약 200~250px, 숫자 카드 높이 170px, 버튼 200px). 시트마다 원본 해상도가 달라서 비율도 달라진다(예: 숫자 카드 0.32, 단독 토끼 0.26).
- 원본 시트는 `art-source/chatgpt/sheet_NN_<내용>.png`로 이름을 바꿔 둔다(`art-source/`는 `.gdignore`로 Godot import 제외). zip 안에는 이전 그림과 첨부한 기준 그림이 중복으로 들어 있으니 md5로 걸러낸다.
- 배경은 자르지 않고 그대로 `assets/backgrounds/`에 복사한다.

## 소리

### 어디서 구하나
| 출처 | 라이선스 | 자동으로 받기 | 메모 |
|---|---|---|---|
| **Kenney** (kenney.nl/assets/category:Audio) | CC0, 출처 표시 불필요 | **가능**. 묶음 페이지 HTML에서 `https://kenney.nl/media/pages/assets/<묶음>/...zip`을 찾아 curl | interface-sounds, ui-audio, impact-sounds, digital-audio, casino-audio, music-jingles, rpg-audio. 짧은 UI·충돌·징글이 많고 **반복 BGM은 없음**. 풍선 펑, 먹기, 날갯짓, 웃음 같은 만화 소리도 약함 |
| **Pixabay** (pixabay.com/ko/sound-effects, /music) | Pixabay 라이선스: 상업 사용 무료, 출처 표시 불필요, 소리 파일만 따로 재배포 금지 | **불가**. 자동 접속은 403, 공식 API는 이미지·영상만 | 사용자가 직접 받는다. BGM과 만화 효과음은 여기서. 받은 페이지 주소를 기록해 둔다. 검색은 영어가 결과가 많다 |

### 진행 방법
1. Kenney 묶음을 `art-source/sounds/kenney/`에 받아 푼다.
2. `tools/asset/oggdur.ps1 <폴더>`로 전체 파일과 길이를 뽑아 이름과 길이로 후보를 고른다(**Claude는 소리를 들을 수 없다**).
3. `art-source/sounds/sfx_candidates.tsv`에 소리마다 후보 3개를 적는다(`interface/click_001`, `jingles/PIZZI07`, 직접 받은 파일은 `file/<경로>`).
4. `bash tools/asset/build_sfx_page.sh art-source/sounds <절대경로>/assets/sounds/sfx` → 1번 후보를 복사하고 `art-source/sounds/listen.html` 듣기 페이지를 만든다. 사용자에게 열어 주고 "이름: 번호"로 고르게 한다.
5. 고른 후보를 TSV의 cand1로 옮기고 다시 실행한다.

효과음 고르는 기준: 1초 이내, 앞에 무음 없음, 날카로운 소리·실패 부저·폭발음 피하기. BGM은 이음매 없이 반복되는 것(loop).
