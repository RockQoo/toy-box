# 블록 쌓기

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 2절(테트리스 스타일 낙하 블록). 게임 방식만 가져오고 아이용으로 바꿨다.

## 게임 목표

위에서 떨어지는 블록을 옮기고 돌려서 가로 한 줄을 빈틈없이 채운다. 채운 줄은 반짝이며 사라진다. 3분 동안 줄을 최대한 많이 지운다.

## 게임 플로우

`꾸미기(난이도 → 배경 → 응원 친구) → 3·2·1 카운트다운 → 3분 플레이 → "끝!" → 결과 화면`

- 시간 제한 게임 공용 구성(`Countdown`, `RoundHud`, `TimerBar`).

## 조작

- PC(원본 그대로): ← → 이동, ↓ 천천히 내리기, SPACE 바로 내리기, ↑ 또는 X 시계 방향 회전, Z 반시계 회전, C 보관(Hold). 키를 누르고 있으면 0.18초 뒤부터 반복 이동.
- 터치: 판 양옆 패널에 큰 버튼. 왼쪽 패널 `ui/btn_left.png`, `ui/btn_right.png`, `ui/btn_down.png`, 오른쪽 패널 `ui/btn_rotate.png`, `ui/btn_drop.png`, `ui/btn_hold.png`. 판 위를 짧게 누르면 회전, 좌우로 끌면 칸 단위 이동(칸 크기만큼마다 한 칸)도 된다.
- 입력은 터치 이벤트만 처리한다.

## 화면 구조

- 원래 세로 장르라 **가운데에 세로 판**(1280x720에서 칸 약 32px, 10 x 20칸, 위에 숨은 2칸), 양옆 패널.
- 왼쪽 패널: 그만하기, 보관 블록, 이동 버튼. 오른쪽 패널: 지운 줄 수, 남은 시간 막대, 다음 블록 3개, 회전·바로 내리기·보관 버튼. 응원 친구는 오른쪽 아래 버튼 위.
- 칸 크기는 화면 높이에서 계산한다.

## 규칙과 판정

- 블록 7종(I O T S Z J L, 원본 그대로). 7개를 한 묶음으로 섞어 차례로 나온다(같은 블록이 오래 안 나오는 일 없음).
- 이동·회전은 벽과 쌓인 블록에 막힌다. 회전이 막히면 옆으로 한 칸 비켜서 돌 수 있으면 돈다(간단한 벽 차기).
- **떨어질 자리 표시**(Ghost)는 항상 켠다(`blocks/ghost.png`).
- 바닥이나 블록에 닿은 뒤 0.8초 동안 움직일 수 있다(원본보다 넉넉하게). 그 뒤 고정된다.
- 가로 줄이 꽉 차면 사라지고 위 블록이 내려온다.
- 보관: 블록마다 한 번.
- **꼭대기까지 쌓이면**: 원본은 게임 끝이지만, 여기서는 친구가 "영차! 자리를 만들자!" 하며 아래쪽 6줄이 반짝이며 사라진다(점수 없음). 판은 계속된다.

## 난이도

**난이도별 랭킹**(`blocks:easy`, `blocks:normal`).

| 변형 | 판 | 처음 낙하 간격 | 빨라지기 |
|---|---|---|---|
| 쉬움 | 8 x 16 | 1.2초 | 10줄마다 조금, 최저 0.6초 |
| 보통 | 10 x 20 | 1.0초 | 10줄마다, 최저 0.35초 |

- 단계가 바뀌면 "빨라져요!" 문구와 음악이 조금 빨라진다.
- 쉬움 판은 칸이 커서(약 40px) 아이가 보기 쉽고 한 줄을 빨리 채운다.

## 점수와 랭킹

- 점수 = 지운 줄 수. 한 번에 여러 줄 지우면 줄 수만큼(원본의 100/300/500/800 대신). 결과와 랭킹은 "줄 N개", 점수 높은 순(`RankOrder.ScoreDesc`). 0줄이면 기록하지 않는다. 보조 줄: "한 번에 가장 많이 N줄".
- 결과 화면 버튼: 다시 하기 / 꾸미기 / 메인으로.

## 연출 강도

- 이동·회전(가장 자주): 블록이 살짝 튀고 아주 작은 "톡".
- 고정: 블록이 납작해졌다 돌아오고 "통".
- 바로 내리기: 위에서 아래로 빛 꼬리, "슝-통", 아주 약한 흔들림.
- 줄 지우기: 빛줄기(`blocks/clear_flash.png`)가 지나가며 칸들이 별로 튀어 흩어짐, 줄 수에 따라 더 큰 "땡"과 문구("한 줄!", "두 줄!", "세 줄!", "네 줄! 최고!"), 네 줄은 색종이와 친구 환호.

## 원본에서 바꾼 점

- **꼭대기 Game Over 없음**: 아래 줄을 정리해 주고 계속한다. 끝은 3분 시간으로 정했다.
- **점수 = 줄 수**: 100/300/500/800 같은 큰 숫자 대신 아이가 셀 수 있는 수.
- **Ghost 항상 켬, 고정 전 0.8초, 쉬움 8x16**: 아이 손에 맞춘 여유.
- **빨강 블록 → 분홍**, 색마다 무늬: 경고색을 피하고 색을 못 구분해도 알아보게.

## 사용 리소스

- `blocks/cyan.png`, `yellow.png`, `purple.png`, `green.png`, `pink.png`, `blue.png`, `orange.png`(I O T S Z J L 순서로 하나씩), `blocks/ghost.png`, `blocks/clear_flash.png`, `ui/btn_left.png`, `btn_right.png`, `btn_down.png`, `btn_rotate.png`, `btn_drop.png`, `btn_hold.png`, `ui/board_frame.png`, `ui/board_bg.png`, `ui/panel.png`, `menu/blocks.png`. 배경 기본 `backgrounds/playroom.png`.
- **리소스가 없을 때**: 칸은 코드로 둥근 사각형 + 윗면 밝은 줄 + 색마다 작은 무늬(점·줄·별 등), Ghost는 흰 점선, 버튼은 `Ui` 팩토리의 둥근 버튼에 기호 글자.

## 구현 메모

- `scripts/Core/BlocksRules.cs`: 판(`int[,]`), 블록 7종 모양과 회전, 충돌, 벽 차기, 7개 묶음 섞기(난수 주입), 줄 지우기, 고정 지연, 꼭대기 정리, 낙하 간격 표(변형별). 단위 테스트 `BlocksRulesTests`.
- `scripts/Games/Blocks/`: 씬 `scenes/games/blocks.tscn`. 공통: `GameCatalog`에 `blocks`(변형 `BlocksRules.Variants`), `Countdown`, `RoundHud`, `ResultPanel`, `QuitConfirm`, `Buddy`. 설정 `[blocks]`(`level`, `scenery`, `buddy`).
- 개발용 `--autoplay`: 가능한 위치·회전 중 구멍이 적고 높이가 낮은 자리를 골라 바로 내린다.

## 완료 조건

- 7종 블록, 7개 묶음 순서, 이동·회전 충돌, 벽 차기.
- 줄 지우기, 다음 3개, 보관, Ghost, 바로 내리기.
- 꼭대기에 닿으면 아래 줄을 정리하고 계속한다.
- 3분 뒤 "끝!" → 결과 화면, 난이도별 Top 10 기록.
- `--game=blocks --autoplay` 스모크 테스트 오류 없음.

- 기획과 달라진 점
  - 칸 크기: 1280x720에서 보통 32px(320x640), 쉬움 40px(320x640). 화면 높이와 양옆 HUD 자리(각 420px)로 계산한다.
  - 회전은 표준 회전계(SRS)의 상자 회전을 쓰고, 벽 차기는 기획대로 간단히: 제자리 → 왼쪽 한 칸 → 오른쪽 한 칸 → (긴 막대만) 두 칸 → 한 칸 위. 바닥에 누운 블록도 세울 수 있게 "한 칸 위"를 넣었다.
  - 고정 유예 0.8초는 움직이거나 돌리면 다시 센다(블록마다 15번까지, 더 낮은 줄로 내려가면 다시 15번). 무한히 미루지 못하게 한 표준 방식.
  - 꼭대기 판정: 새 블록이 나올 자리가 막히거나 고정된 블록이 숨은 줄에 걸치면 "영차! 자리를 만들자!" → 아래 6줄이 노랗게 반짝이며 사라지고 별이 튄다. 그래도 모자라면 6줄씩 더 걷는다.
  - 속도 단계 표: 쉬움 1.2 → 1.1 → 1.0 → 0.9 → 0.8 → 0.7 → 0.6초, 보통 1.0 → 0.85 → 0.72 → 0.6 → 0.5 → 0.42 → 0.35초(10줄마다). 단계가 바뀌면 친구 응원 + "빨라져요!" + 음악 4%씩 빨라짐. 천천히 내리기는 0.05초/칸, 키 반복은 0.18초 뒤 0.05초마다.
  - 터치 버튼은 일반 Button이 아니라 그림만 두고 게임이 터치 번호별로 직접 판정한다(◀를 누른 채 회전을 누르는 여러 손가락 입력과 누르고 있기 때문). 오른쪽 아래 줄은 보관 · 바로 내리기 · 회전(가장 자주 쓰는 회전이 가장 크고 가장자리).
  - 판 위 입력: 짧게 누르면 회전, 옆으로 끌면 칸 크기마다 한 칸, 아래로 끌면 칸마다 한 칸 내리기(기획에는 없지만 같은 방식이라 넣음).
  - PC 키: 기획 키에 더해 A/D/S/W, Shift(보관)도 된다.
  - 배경은 다른 게임처럼 공용 `Scenery`(기본 하늘)라 `playroom.png`, `ui/board_bg.png`, `ui/panel.png`는 쓰지 않았다(판은 코드로 그린 크림색 패널 + `ui/board_frame.png`, HUD 칸은 공용 흰 패널).
  - 소리는 기존 합성음: 이동·회전 `Step`(0.08초에 한 번까지), 막힌 회전 `Plop` + 고개 젓기, 고정 `WallBump`("통"), 바로 내리기 `Whoosh`, 줄 `MatchChime(줄 수)`, 네 줄 `Fanfare`, 보관 `CardFlip`, 꼭대기 정리 `Whoosh`·`StarPickup`.
- 자동 플레이(`--autoplay`)
  - 블록마다 가능한 회전·칸을 모두 놓아 보고 다음 블록까지 한 수 더 내다봐서(높이·구멍·울퉁불퉁함·지운 줄) 자리를 고른 뒤, 버튼을 누르듯 보관 → 회전 → 한 칸씩 이동 → 바로 내리기. 6번째 블록마다 천천히 내리기로 내려 고정 유예를 기다린다. 12번째 블록부터 한 번은 가운데에만 바로 내려 꼭대기 정리도 돌린다.
  - 헤드리스 자동 플레이만 5배속(`Engine.TimeScale = 5`, 3분 판). 두 난이도 모두 8000프레임 안에 결과·기록 저장까지 간다(봇 기준 쉬움 약 70~96줄, 보통 약 50~70줄).
