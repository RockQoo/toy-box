# 공룡 점프

## 게임 목표

자동으로 달리는 공룡을 점프시켜 장애물을 피하고 최대한 오래 달린다.

## 게임 플로우

`공룡 선택 → 배경 선택 → 시작 → 자동 달리기 → 장애물 생성 → 점프 → 장애물 회피 → 속도 증가 → 충돌 / 시간 종료 → 결과 화면`

## 조작

PC:

- SPACE
- 마우스 클릭

모바일:

- 화면 어디든 터치

한 버튼만 사용하는 구조로 만든다.

## 화면 구조

```text
                        구름

              선인장

   공룡
____________________________
```

공룡은 화면 왼쪽 근처에 위치하고, 장애물과 배경이 오른쪽에서 왼쪽으로 움직인다.

## 점프

입력 시:

```text
상승
↓
최고점
↓
낙하
↓
착지
```

공중에서는 추가 점프가 되지 않도록 한다.

## 장애물

초기 버전:

- 선인장 1종

확장:

- 작은 돌
- 큰 선인장
- 통나무

## 점수

장애물을 하나 통과할 때마다:

- 점수 +1

또는 생존 시간을 그대로 점수로 사용할 수도 있다.

## 난이도 증가 예시

| 플레이 시간 | 게임 속도 |
|---|---:|
| 시작 | 1.0 |
| 10초 | 1.2 |
| 20초 | 1.5 |
| 30초 | 1.8 |

게임 속도가 올라갈수록 장애물 생성 간격도 조금씩 줄인다.

## 충돌

장애물에 닿으면:

- 공룡 넘어짐 애니메이션
- 효과음
- 게임 정지

아이용 메시지:

```text
앗!
다시 해볼까요?
```

## 결과 화면

```text
점수
12점

최고 기록
18점

[다시 하기]
[공룡 바꾸기]
[메인으로]
```
