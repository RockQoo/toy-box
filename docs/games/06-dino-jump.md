# 공룡 점프

## 게임 목표

자동으로 달리는 공룡을 점프시켜 장애물을 피하고 최대한 오래 달린다.

## 게임 플로우

`공룡 선택 → 배경 선택 → 시작 → 자동 달리기 → 장애물 생성 → 점프 → 장애물 회피 → 속도 증가 → 충돌 / 시간 종료 → 결과 화면`

## 조작

PC:

- SPACE
- 마우스 클릭

모바일:

- 화면 어디든 터치

한 버튼만 사용하는 구조로 만든다.

## 화면 구조

```text
                        구름

              선인장

   공룡
____________________________
```

공룡은 화면 왼쪽 근처에 위치하고, 장애물과 배경이 오른쪽에서 왼쪽으로 움직인다.

## 점프

입력 시:

```text
상승
↓
최고점
↓
낙하
↓
착지
```

공중에서는 추가 점프가 되지 않도록 한다.

## 장애물

초기 버전:

- 선인장 1종

확장:

- 작은 돌
- 큰 선인장
- 통나무

## 점수

장애물을 하나 통과할 때마다:

- 점수 +1

또는 생존 시간을 그대로 점수로 사용할 수도 있다.

## 난이도 증가 예시

| 플레이 시간 | 게임 속도 |
|---|---:|
| 시작 | 1.0 |
| 10초 | 1.2 |
| 20초 | 1.5 |
| 30초 | 1.8 |

게임 속도가 올라갈수록 장애물 생성 간격도 조금씩 줄인다.

## 충돌

장애물에 닿으면:

- 공룡 넘어짐 애니메이션
- 효과음
- 게임 정지

아이용 메시지:

```text
앗!
다시 해볼까요?
```

## 결과 화면

```text
점수
12점

최고 기록
18점

[다시 하기]
[공룡 바꾸기]
[메인으로]
```

## 구현에 필요한 주요 오브젝트

- GameManager
- Dino
- ObstacleSpawner
- Obstacle
- Ground
- BackgroundScroller
- Score UI
- Result UI
- AudioManager



## 구현 결정

기획서에서 정하지 않은 부분은 다음과 같이 정했다(2026-10-17). 코드: `scripts/Games/Dino/`, 규칙·수치: `scripts/Core/DinoRules.cs`(`DinoRules`, `DinoJump`).

- **흐름**: 꾸미기(공룡 → 배경 → 속도) → 3·2·1 카운트다운(공용 `Countdown`, 이때부터 공룡은 제자리에서 달린다) → 자동 달리기 → 부딪히면 넘어짐 → "앗! 다시 해볼까요?" → 공통 결과 화면(다시 하기 / 공룡 바꾸기 / 메인으로). 플레이 중 "그만하기"는 다른 게임처럼 "정말 그만할까요?"를 묻는다. 시간 제한은 없다(기획서의 "시간 종료"는 쓰지 않음).
- **충돌은 기획서대로 판을 끝내되 부드럽게**: 공룡이 뒤로 살짝 튀며 반 바퀴 굴러 엎드린 포즈(`dino_crouch.png`)로 주저앉고 머리 위로 별이 돈다. 소리는 만화 같은 "뿌우웅~ 통"(`SfxSynth.Tumble`), 화면은 약하게 한 번 흔들리고 배경이 0.3초 동안 미끄러지듯 멈춘다. 부딪힌 선인장은 살짝 흔들린다. 붉은색·경고음 없음. 0.45초 뒤 "앗! 다시 해볼까요?", 2초 뒤 결과 화면(첫 버튼이 "다시 하기").
- **조작**: 한 버튼. SPACE(↑, W도 됨), 마우스 클릭, 화면 어디든 터치(`emulate_touch_from_mouse`라 터치 이벤트만 처리). 공중에서는 다시 뛰지 않는다. 꾸미기 화면에서도 오른쪽 빈 곳을 누르면 공룡이 뛰어 미리 해 볼 수 있다. 판 시작 후 첫 점프 전까지 "화면을 누르면 점프!"가 깜박인다.
- **넉넉한 판정**(아이용):
  - 충돌 상자는 그림보다 훨씬 작다. 공룡은 몸통만(폭 0.10, 높이 0.16, 발보다 0.02 위. 단위는 화면 높이), 선인장은 줄기만(작은 선인장 0.05 x 0.115, 큰 선인장 0.065 x 0.16), 돌은 0.11 x 0.07.
  - **점프 버퍼**: 착지 0.15초 전까지 누른 입력은 착지하는 순간 바로 다시 뛴다.
  - **늦은 점프 유예**: 장애물에 0.08초 동안 계속 닿아야 넘어진다. 그 사이에 누르면 그대로 떠올라 넘을 수 있다(평지만 달리므로 발판 끝에서 쓰는 보통의 코요테 타임 대신 이것을 쓴다).
- **점프**: 정해진 포물선(높이 0.40, 0.75초, 달리는 속도와 무관). 상승 → 최고점 → 낙하 → 착지. 뛸 때 위로 늘어나고(점프 그림으로 바뀜), 올라갈 때 고개를 들고 내려올 때 숙이며, 착지하면 납작해졌다 튀어 돌아온다. "보잉" 소리(`SfxSynth.Jump`)와 발밑 먼지.
- **달리기**: 달리기 그림이 한 장뿐이라 걸음마다 위아래로 통통 튀고, 앞뒤로 살짝 기울고, 발이 닿을 때 조금 납작해지는 것으로 달리는 느낌을 낸다. 걸음 빠르기는 달리는 속도를 따라가고, 걸음마다 작은 먼지가 난다.
- **속도**(화면 높이/초, 기본 0.55에 배율을 곱함): 기획서 표대로 0초 1.0 → 10초 1.2 → 20초 1.5 → 30초 1.8, 그 뒤 45초 2.0에서 멈춘다(상한). 단계가 바뀔 때 1초에 걸쳐 부드럽게 빨라지고, "빨라져요!" / "더 빨라져요!" / "엄청 빨라요!" / "최고 속도!" 문구, 바람 줄무늬, "슝" 소리가 나오고 음악이 조금씩 빨라진다. 꾸미기의 "속도"(느림 0.75 / 보통 1 / 빠름 1.3배)를 전체에 곱한다.
- **장애물**: 선인장(작은 것, 큰 것)과 돌. 처음 10초는 작은 선인장과 돌만, 그 뒤 큰 선인장이 섞인다.
  - **간격**: 무작위 시간 간격(처음 1.6~2.6초 → 최고 속도에서 1.05~1.7초)에 달리는 속도를 곱한 거리. 단, **최소 간격**(달리는 속도 x (점프 시간 + 반응 시간 0.4초) + 가장 넓은 장애물 폭 + 공룡 폭)보다 짧아지지 않는다. 앞 장애물을 가장 늦게 넘은 아이도 착지 후 0.4초 이상 여유가 있다. 모든 장애물이 가장 느린 속도에서도 0.18초 이상의 점프 타이밍 폭을 가진다. 둘 다 `DinoRulesTests`가 모든 속도·장애물 조합으로 확인한다.
- **익룡**: 엎드려 피해야 하는 장애물은 한 버튼 구조에 맞지 않아 **배경 장식**으로만 쓴다. 6초 뒤부터 14~22초마다 높이 날며 공룡과 같은 방향으로 날다가 천천히 뒤로 처진다. 닿아도 아무 일 없다.
- **알·별 수집**: 쓰지 않았다(확장 기능, 개선 D-7).
- **점수**: 장애물을 하나 넘을 때마다 +1(장애물이 공룡 뒤로 완전히 지나가면). 결과와 랭킹은 "N점"(점수 높은 순, 공통 `RankOrder.ScoreDesc`, 기록의 `TimeMs`에 달린 시간). 0점은 기록하지 않는다. 결과 화면 보조 줄에 "N초 동안 달렸어요".
- **연출 강도**(`/polish-review` 3절): 점프(가장 자주)는 가볍게: 늘어남, "보잉", 먼지. 장애물 통과는 한 단계 위: 10개 안에서 한 음씩 올라가는 "띵"(`SfxSynth.PassTick`), 장애물 위 "+1"과 작은 별 3개, 장애물이 살짝 출렁, 점수 튀기. 10점마다는 중요하게: 반짝 소리, 공룡 머리에서 별 소나기, 공룡이 반짝, 화면 가운데 "10점! 최고야!", 약한 흔들림. 속도 단계는 문구와 바람 줄무늬. 충돌·결과는 클라이맥스지만 부드럽게(위 충돌 항목, 결과 화면은 공통 축하).
- **공룡 선택**: 초록 공룡 그림 하나뿐이라 색(초록·파랑·보라·분홍·노랑)만 고른다. 셰이더가 **초록 피부색만** 색상(hue)을 돌리고 주황 등 가시·크림색 배·눈·테두리는 그대로 둔다(과일 받기 바구니는 그림 전체를 돌림). 다른 공룡 그림이 생기면 모양 선택으로 바꾼다(`docs/resources.md`).
- **배경**: 하늘은 공용 `Scenery`(기본값 하늘). 그 위에 코드로 그리는 패럴랙스: 먼 산(0.08배), 가까운 산(0.22배), 땅(1배, `ground.png`를 이어 붙임, 아래는 흙색으로 채움). `Scenery`의 구름은 `CloudDrift`를 음수로 주어 가장 먼 층으로 왼쪽으로 흐른다(공용 기능 추가, 다른 게임은 그대로).
- **꾸미기 화면**: 왼쪽 패널(공룡 / 배경 / 속도, 메인으로 / 시작!), 오른쪽에서 공룡이 고른 색과 속도로 달린다. 색을 바꾸면 한 번 뛴다. `settings.cfg`의 `[dino]` 섹션(`color`, `scenery`, `speed`)에 저장한다.
- **응원 친구 없음**: 가로로 달리는 화면이라 오른쪽 아래 응원 친구가 장애물과 겹쳐 넣지 않았다.
- **개발용**: `-- --game=dino --autoplay`는 장애물마다 점프 타이밍 폭의 한가운데에서 뛴다(`DinoRules.IdealJumpIn`). 25~40점 중 무작위 점수에 이르면 다음 장애물에서 뛰지 않아 넘어지고 결과 화면까지 간다. 꾸미기 화면에서 한 번 뛰어 본 뒤 시작한다.
