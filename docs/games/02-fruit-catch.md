# 과일 받기

## 게임 목표

30초 동안 위에서 떨어지는 과일을 바구니로 최대한 많이 받는다.

## 게임 플로우

`메인 화면 → 바구니 선택 → 과일 선택 → 배경 선택 → 시작 → 3초 카운트다운 → 플레이 → 30초 종료 → 결과 화면`

## 조작

PC:

- 마우스 좌우 이동
- 또는 방향키 ← →

모바일:

- 손가락으로 바구니 드래그

아이용으로는 **마우스나 손가락 위치를 따라 바구니가 이동하는 방식**이 가장 단순하다.

## 플레이 규칙

화면 상단의 랜덤 위치에서 과일이 생성되고 아래로 떨어진다.

```text
     사과

            오렌지

  딸기


       바구니
```

과일이 바구니에 닿으면:

- 점수 +1
- “뿅!” 효과음
- 반짝임 효과
- 해당 과일 제거

과일이 바닥에 떨어지면:

- 해당 과일 제거
- 감점 없음

## 과일 종류

- 사과
- 딸기
- 바나나
- 오렌지
- 포도

아이가 원하는 과일만 등장하도록 선택 기능을 넣어도 된다.

## 난이도

### 0~10초
- 과일 1개씩 생성
- 느린 낙하 속도

### 10~20초
- 낙하 속도 증가
- 생성 간격 감소

### 20~30초
- 과일 2~3개가 거의 동시에 등장
- 낙하 속도 추가 증가

## 보너스 과일

황금 사과 등 특별한 과일을 일정 확률로 등장시킬 수 있다.

- 일반 과일: +1
- 황금 과일: +3

## 결과 화면

```text
과일을 27개 받았어요!

최고 기록
35개

[다시 하기]
[메인으로]
```
