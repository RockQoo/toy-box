# 과일 받기

## 게임 목표

30초 동안 위에서 떨어지는 과일을 바구니로 최대한 많이 받는다.

## 게임 플로우

`메인 화면 → 바구니 선택 → 과일 선택 → 배경 선택 → 시작 → 3초 카운트다운 → 플레이 → 30초 종료 → 결과 화면`

## 조작

PC:

- 마우스 좌우 이동
- 또는 방향키 ← →

모바일:

- 손가락으로 바구니 드래그

아이용으로는 **마우스나 손가락 위치를 따라 바구니가 이동하는 방식**이 가장 단순하다.

## 플레이 규칙

화면 상단의 랜덤 위치에서 과일이 생성되고 아래로 떨어진다.

```text
     사과

            오렌지

  딸기


       바구니
```

과일이 바구니에 닿으면:

- 점수 +1
- “뿅!” 효과음
- 반짝임 효과
- 해당 과일 제거

과일이 바닥에 떨어지면:

- 해당 과일 제거
- 감점 없음

## 과일 종류

- 사과
- 딸기
- 바나나
- 오렌지
- 포도

아이가 원하는 과일만 등장하도록 선택 기능을 넣어도 된다.

## 난이도

### 0~10초
- 과일 1개씩 생성
- 느린 낙하 속도

### 10~20초
- 낙하 속도 증가
- 생성 간격 감소

### 20~30초
- 과일 2~3개가 거의 동시에 등장
- 낙하 속도 추가 증가

## 보너스 과일

황금 사과 등 특별한 과일을 일정 확률로 등장시킬 수 있다.

- 일반 과일: +1
- 황금 과일: +3

## 결과 화면

```text
과일을 27개 받았어요!

최고 기록
35개

[다시 하기]
[메인으로]
```

## 구현 결정

기획서에서 정하지 않은 부분은 다음과 같이 정했다(2026-10-17). 코드: `scripts/Games/Fruit/`, 규칙·수치: `scripts/Core/FruitRules.cs`.

- **흐름**: 풍선 터뜨리기와 같다. 꾸미기 → 3·2·1 카운트다운 → 30초 → "끝!" → 공통 결과 화면(다시 하기 / 꾸미기 / 메인으로). 플레이 중 "그만하기"는 "정말 그만할까요?"를 한 번 묻는다.
- **꾸미기 화면**: 바구니 → 과일 → 배경 → 응원 친구 → 속도, 한 화면에 다섯 줄. 고른 값은 `settings.cfg`의 `[fruit]` 섹션에 저장한다.
  - **바구니**: 바구니 그림이 하나뿐이라 색(기본·분홍·파랑·초록)만 고른다. 색상(hue)을 돌리는 셰이더로 다시 칠한다. 다른 모양 바구니 그림이 생기면 모양 선택으로 바꾼다.
  - **과일**: 여러 개를 켜고 끌 수 있다(공통 `ChoiceRow.CreateMulti`). 마지막 하나는 끌 수 없다(살짝 흔들리고 "통" 소리). 기본값은 기획서의 다섯 가지이고, 수박은 꺼져 있다(켤 수 있음).
  - **배경**: 공통 `Scenery`. 기본값은 공원.
  - **속도**: 풍선과 같은 느림/보통/빠름. 떨어지는 속도와 생성 간격에 곱한다.
  - 오른쪽 빈 곳에서 고른 과일이 바구니에 떨어져 고른 색과 과일이 바로 보인다(점수 없음). 화면이 넓으면 바구니를 손가락으로 움직여 볼 수 있다.
- **조작**: 바구니는 가로로만 움직이고 손가락/마우스의 x 위치를 부드럽게 따라간다(누르기, 드래그, PC에서는 마우스만 움직여도 됨). ← → / A D 키로도 움직인다. 화면 어디를 눌러도 되므로 바구니를 손가락으로 가리지 않아도 된다.
- **받기 판정**: 과일 아랫부분이 바구니 입구 높이를 지나는 순간 입구 폭 안에 있으면 받은 것으로 친다(입구 폭은 그림보다 넉넉하게). 떨어지는 과일은 바구니 앞에 그리고, 받으면 바구니 뒤로 쏙 들어간다.
- **난이도**(화면 높이/초, 속도 "보통" 기준):

  | 시간 | 낙하 속도 | 생성 간격 | 한 번에 |
  |---|---|---|---|
  | 0~10초 | 0.24 | 1.10초 | 1개 |
  | 10~20초 | 0.32 | 0.85초 | 1개 |
  | 20~30초 | 0.40 | 1.20초 | 2~3개(0.18초 간격) |

  단계가 바뀌면 "과일이 빨라져요!", "과일이 우르르!" 문구가 나오고 음악이 조금 빨라진다.
- **황금 과일**: 황금 사과 그림이 없어 동전(`fruit/coin.png`)을 쓴다. 3초 이후 과일마다 7% 확률, 화면에 한 개까지, 조금 느리게 떨어진다. 빙글 도는 듯 보이고 은은하게 빛난다. 받으면 +3.
- **점수**: 일반 +1, 황금 +3. 결과와 랭킹은 "받은 과일 N개"(황금 과일은 3개로 센다). 0개면 기록하지 않는다.
- **바닥에 떨어진 과일**: 바닥에서 살짝 찌그러졌다가 사라지고 아주 작은 "톡" 소리만 난다. 감점 없음.
- **연출 강도**: 받기(자주 일어남)는 짧고 가볍게: 바구니 찌그러짐, 과일 색 불꽃 몇 개, 작은 별 3개, "+1", "뿅" 소리(1.2초 안에 연속으로 받으면 음이 올라감), 응원 친구 깡충. 황금 과일은 한 단계 크게: "띠링" 소리, 금색 고리와 별, 큰 "+3", 친구가 "반짝반짝!". 10개마다(+3으로 10을 넘겨도) 반짝 소리, 별 소나기, 약한 화면 흔들림, 친구 응원 말풍선. 시간이 끝나면 남은 과일은 사라지고 바구니가 한 번 뛴다.
- **폭탄 없음**: 아이용 원칙(실패 연출 없음)에 따라 `fruit/bomb.png`는 쓰지 않는다.
- **개발용**: `-- --game=fruit --autoplay`에서는 바구니가 가장 먼저 닿을 과일(황금 과일 우선) 쪽으로 스스로 움직인다.
