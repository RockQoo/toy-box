# 그림 스도쿠

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 4절(스도쿠). 게임 방식만 가져오고 아이용으로 바꿨다.

## 게임 목표

빈 칸에 동물 얼굴을 채운다. 가로줄, 세로줄, 굵은 선으로 나눈 상자 안에 같은 동물이 한 번씩만 나오면 완성.

## 게임 플로우

`꾸미기(난이도 → 배경 → 응원 친구) → 판이 나타나고 처음부터 있는 동물이 톡톡 놓임 → 칸 고르기 → 동물 고르기 → … → 다 채움 → "완성!" → 결과 화면`

- 시간 제한 게임이 아니어서 카운트다운이 없다. 시계는 첫 입력부터 간다(작고 옅게).

## 조작

- 터치: 칸을 누르고 아래 동물 버튼을 누르면 놓인다. 동물 버튼을 먼저 고르고 칸을 차례로 눌러도 된다(고른 동물이 유지됨). 둘 다 된다.
- 놓은 동물을 다시 누르고 지우개(`ui/erase.png`)를 누르면 지운다. 같은 동물을 한 번 더 놓으면 지워진다.
- PC: 마우스는 터치와 같이 동작. 방향키로 칸 이동, 1~6 키로 동물, Delete/Backspace로 지우기.
- 입력은 터치 이벤트만 처리한다.

## 화면 구조

- 가운데에 정사각형 판(1280x720에서 4x4는 칸 약 140px, 6x6은 약 100px), 판 오른쪽에 동물 버튼 세로 줄(4개 또는 6개, `sudoku/btn_bg.png`), 그 아래 지우개·연필(메모)·힌트(`ui/hint.png`) 버튼. 왼쪽 패널: 그만하기, 시계, 응원 친구.
- 고른 칸은 밝은 노랑 테두리(`ui/cell_select.png`), 같은 줄·세로줄·상자는 아주 옅게 밝힌다(원본의 행/열 강조). 고른 동물과 같은 동물이 놓인 칸도 살짝 밝힌다.

## 규칙과 판정

- 판: 4x4(상자 2x2, 동물 4종), 6x6(상자 2x3, 동물 6종). 원본의 9x9는 아이에게 너무 커서 쓰지 않는다.
- **처음부터 놓인 동물**은 바꿀 수 없다(조금 진한 바탕).
- **겹침 알림**: 같은 줄·세로줄·상자에 이미 같은 동물이 있는 칸에 놓으면, 두 동물이 살짝 흔들리며 고개를 갸웃하고 "통" 소리가 난 뒤 방금 놓은 동물이 톡 빠진다(놓이지 않음). 원본의 "오답 즉시 표시"(빨강)를 대신한다. 정답과 비교하지 않고 눈에 보이는 규칙만 알려 준다.
- 모든 칸이 차면 완성. 문제는 답이 하나뿐이도록 만들므로, 겹침 없이 다 채우면 항상 정답이다.
- **메모(연필)**: 6x6에서만 버튼이 나온다. 켜면 칸에 연한 스케치 동물(`sudoku/<동물>_memo.png`)을 여러 개 적어 둘 수 있다.
- **힌트(전구)**: 누르면 빈 칸 하나에 맞는 동물이 반짝이며 놓인다. 감점 없음, 결과 화면 보조 줄에 "힌트 N번"만 적는다.

## 난이도

**난이도별 랭킹**(`sudoku:easy`, `sudoku:normal`, `sudoku:hard`).

| 변형 | 판 | 빈 칸 |
|---|---|---|
| 쉬움 | 4x4 | 6칸 |
| 보통 | 6x6 | 14칸 |
| 어려움 | 6x6 | 20칸 |

- 문제는 Core 생성기가 시드에서 만든다(답 하나뿐 확인). 난이도마다 미리 고른 시드 10개, "다음 문제"로 차례로 돈다. 같은 난이도의 문제들은 한 표를 같이 쓴다.

## 점수와 랭킹

- 랭킹: 걸린 시간 짧은 순(`RankOrder.TimeAsc`). 끝까지 하면 기록 대상이다. 원본의 "실수" 횟수는 세지 않는다(겹친 동물은 놓이지 않으므로). 힌트는 기록에 영향을 주지 않고 보조 줄에만 보여 준다(아이가 힌트를 편하게 쓰게).
- 결과 화면: "완성!" / "걸린 시간" / "N.N초" / "힌트 N번"(0번이면 "힌트 없이 했어요!"). 버튼: 다음 문제 / 다시 하기 / 메인으로.

## 연출 강도

- 동물 놓기(자주): 동물이 톡 튀어 나타나며 짧은 동물 소리 같은 "뿅"(동물마다 다른 음 높이).
- 한 줄·세로줄·상자 완성: 그 줄이 물결처럼 뛰고 반짝, 올라가는 "띵".
- 완성: 모든 동물이 차례로 뛰며 웃고, 팡파르, 색종이, "완성!".

## 원본에서 바꾼 점

- **숫자 → 동물 얼굴, 9x9 → 4x4/6x6**: 숫자를 모르는 아이도 할 수 있게.
- **빨간 오답 표시 없음**: 겹치면 놓이지 않고 귀엽게 흔들리기만. 실수 횟수를 세지 않는다.
- **힌트 감점 없음**, **전문가 난이도 없음**.

- **리소스가 없을 때**: 지금 있는 `assets/sprites/animal/`의 동물 카드(lion, elephant, penguin, rabbit, fox, panda)를 칸에 맞게 줄여 쓴다. 메모 그림은 같은 그림을 회색·반투명으로. 버튼은 `Ui` 팩토리.

## 구현 메모

- `scripts/Core/SudokuRules.cs`: 판 크기·상자 모양, 정답 판 생성과 칸 비우기(답 하나뿐 검사, 자체 난수로 결정적), 겹침 검사, 완성 판정, 힌트 칸 고르기. 단위 테스트 `SudokuRulesTests`(모든 시드가 답 하나, 빈 칸 수, 첫 문제 모양 고정).
- `scripts/Games/Sudoku/`: 씬 `scenes/games/sudoku.tscn`. 공통: `GameCatalog`에 `sudoku`(변형 `SudokuRules.Variants`), `ResultPanel`, `QuitConfirm`, `Buddy`. 설정 `[sudoku]`(`level`, `next_*`, `scenery`, `buddy`).
- 개발용 `--autoplay`: 답이 하나뿐인 칸부터 1초 간격으로 놓는다. 두 번에 한 번은 겹치는 동물을 먼저 놓아 본다.

## 완료 조건

- 칸 → 동물, 동물 → 칸 두 방식 모두 놓을 수 있다. 처음 동물은 바뀌지 않는다.
- 겹치면 놓이지 않고 흔들린다. 다 채우면 완성.
- 메모(6x6), 힌트, 지우기 동작.
- 생성 문제가 모두 답 하나뿐(단위 테스트).
- 결과 화면, 난이도별 Top 10 기록. `--game=sudoku --autoplay` 스모크 테스트 오류 없음.

- 기획과 달라진 점
  - 문제: 생성기 + 난이도마다 시드 10개(11~20, 21~30, 31~40). 답 하나뿐에 더해 **짐작 없이 한 칸씩 풀리는 문제만** 만든다(아이가 찍지 않아도 되게). 빈 칸은 상자를 돌아가며 골라 판 전체에 퍼진다.
  - 화면: 왼쪽 그만하기·"어려움 · 2번 문제"·작은 시계("누르면 시계가 가요" → "N초"), 왼쪽 아래 응원 친구. 동물 버튼은 세로 한 줄이 아니라 **2열**(6개를 한 줄로 두면 720 높이에 도구까지 들어가지 않음). 버튼 왼쪽 위에 PC 숫자 키를 작게 적었다. 판에 다 놓인 동물의 버튼은 흐려진다(눌러지기는 함).
  - 칸 크기: 1280x720에서 4x4 140px, 6x6 약 98px.
  - 두 방식: 고른 동물이 없을 때는 칸 → 동물 버튼으로 놓는다. 칸을 고르지 않고(또는 처음 동물 칸을 고른 채) 동물 버튼을 누르면 그 동물을 "들고"(노란 버튼) 칸을 누를 때마다 놓는다. 든 동물 버튼을 다시 누르면 내려놓는다. 동물을 들고 있는 동안 다른 동물 버튼은 바꿔 들기만 한다.
  - 겹침: 새 동물이 칸에 톡 나타나 갸웃하고, 이미 있던 같은 동물(들)도 갸웃, 0.15초 뒤 "통"(`WallBump`)과 약한 진동, 새 동물이 톡 튀어 사라진다. 친구가 "사자가 벌써 있어요!"(4초에 한 번까지).
  - 지우개: 고른 칸의 동물(없으면 메모)을 지운다. **되돌리기**(`ui/undo.png`, 기획에 없던 버튼)를 더했다: 놓기·빼기·지우기·메모를 한 단계씩 되돌리고 힌트 너머로는 가지 않는다.
  - 힌트: 고른 칸이 비어 있으면 그 칸, 아니면 들어갈 동물이 가장 적은 칸에 정답 동물이 반짝이며 놓이고 처음 동물처럼 잠긴다. 아이가 놓은 틀린(겹치지 않는) 동물 때문에 빈 칸이 모두 막히면, 틀린 칸 하나를 정답으로 바꾸고 그와 겹치는 동물을 빼 준다(정답과 비교하는 건 이 경우뿐).
  - 메모(6x6만): 켜면 버튼 아래 글자가 "메모 켜짐"(초록). 동물을 놓으면 그 칸의 메모와 같은 줄·세로줄·상자의 같은 동물 메모가 저절로 지워진다.
  - 동물 놓기 소리 `Pop(동물 번호)`(동물마다 음 높이), 줄·세로줄·상자 완성 `MatchChime`(판에서 완성할수록 올라감) + 놓은 칸에서 퍼지는 물결 폴짝 + 별. 완성: 판 대각선 물결로 모두 폴짝, `Fanfare`, 색종이, "완성!", 친구 "다 했다!".
  - 결과: "완성!" / "걸린 시간" / "N.N초" / "힌트 N번"(0번이면 "힌트 없이 했어요!"). 기록 `Score`에는 힌트 수를 넣지만 순위는 시간만 본다.
  - PC 키: 방향키·WASD 칸 이동(처음 누르면 첫 빈 칸), 1~6(숫자패드도) 고른 칸에 놓기, Delete/Backspace/0 지우기, M 메모, H 힌트, Z/U 되돌리기.
  - 배경은 공용 `Scenery`(기본 공원), 응원 친구 기본은 토끼. `garden.png`는 쓰지 않았다.
- 자동 플레이(`--autoplay`)
  - 0.9초마다 한 동작. 매번 `NextSure`로 확실한 칸을 찾아 칸 → 동물로 놓고, 홀수 번째에는 그 칸에 겹치는 동물을 먼저 눌러 본다. 앞쪽에서 한 번씩 동물 들고 놓기, 메모(6x6: 스케치 두 개 → 메모 끄고 놓기), 힌트, 놓고 되돌리기, 놓고 지우기를 지나간다.
  - 배속 없이 8000프레임 안에 끝난다(쉬움 약 12초, 어려움 약 42초 + 결과 화면).
