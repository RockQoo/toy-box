# 하늘 비행 모험

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 6절(탄막 슈팅). 장르만 가져와 아이용 횡스크롤 비행 게임으로 바꿨다.

## 게임 목표

토끼가 작은 비행기를 타고 오른쪽으로 날아가며 비눗방울을 쏜다. 장난꾸러기 먹구름·꿀벌·꼬마 UFO에 비눗방울을 맞히면 웃는 구름으로 바뀌고 별이나 사탕을 떨어뜨린다. 마지막에 나오는 "대장 먹구름"을 웃게 만들면 끝.

## 게임 플로우

`꾸미기(난이도 → 속도) → 3·2·1 카운트다운 → 비행(약 90초, 장난꾸러기 무리가 차례로 나옴) → "대장 먹구름이 나타났어요!" → 대장 먹구름(최대 60초) → 대장이 하얀 구름으로 웃음 → "모두 깨끗해졌어요!" → 결과 화면`

- 플레이 중 "그만하기"는 "정말 그만할까요?"를 묻는다. 비행 진행도는 위쪽 작은 길 막대(토끼 비행기 아이콘이 오른쪽으로 감)로 보여 준다.

## 조작

- 비눗방울은 **항상 자동으로 쏜다**(PC·터치 모두). 아이는 움직이기만 하면 된다.
- 터치: 화면 어디든 누르고 끌면 비행기가 손가락의 움직인 만큼 따라간다(손가락 아래로 순간 이동하지 않고 상대 이동, 손가락이 비행기를 가리지 않음). 오른쪽 아래 폭죽 버튼(`flight/item_bomb.png`, 가진 개수 표시).
- PC: 방향키 / WASD 이동, SHIFT 천천히 이동(원본 그대로), B 또는 X 폭죽. 마우스는 터치와 같이 동작한다.
- 입력은 터치 이벤트만 처리한다.

## 화면 구조

- 가로 화면 전체를 쓴다. 비행기는 왼쪽 1/3 안에서만 움직인다(앞쪽을 볼 여유). 배경 2층(`bg_far` 느리게, `bg_near` 빠르게)이 왼쪽으로 흐른다.
- 위: 그만하기, 길 막대, 점수("별 34"). 아래 오른쪽: 폭죽 버튼. 대장 먹구름이 나오면 위쪽에 대장의 "기분 막대"(먹구름 → 웃는 구름, 빨간 HP 막대 대신).

## 규칙과 판정

- **내 방울**: 레벨 1~4(원본 Lv1~4: 2발 → 3갈래 → 5갈래 → 큰 별 5갈래). 번개 아이템(`item_power`)을 먹으면 한 단계 오른다. 맞아도 내려가지 않는다.
- **장난꾸러기**(원본 적 4종에 대응): 작은 먹구름(직선), 꿀벌(위아래 물결), 꼬마 UFO(멈춰서 느린 방울을 비행기 쪽으로 쏨), 번개구름(조금 크고 여러 번 맞아야 함, 부채꼴 방울). 맞히면 터지는 대신 웃는 구름(`enemy_happy`)으로 바뀌어 위로 둥실 떠나며 별을 떨어뜨린다.
- **적 방울**: 원본의 탄막 패턴 중 원형·부채꼴·조준만 쓰고 나선·교차는 쓰지 않는다. 모두 느리고 개수가 적으며, 흰 바탕에 파스텔 색(분홍·하늘·연보라)을 입힌다(붉은색 없음).
- **맞으면**: 원본은 Life -1이지만, 여기서는 비행기가 깜짝 놀란 얼굴(`plane_surprised`)로 빙글 한 바퀴 돌고 "앗!" 1.5초 동안 깜박이며 무적. **목숨·점수·방울 레벨은 줄지 않는다.** 주변 적 방울은 그 순간 비눗방울로 바뀌어 사라진다(연속으로 맞지 않게). 결과 화면에 맞은 횟수는 보여 주지 않는다.
- 충돌 판정은 비행기 가운데 작은 원(그림 폭의 20%, 원본의 작은 HitBox). SHIFT로 천천히 갈 때 그 점이 보인다.
- **아이템**: 번개(방울 강화), 폭죽(화면의 적 방울을 모두 별로 바꾸고 장난꾸러기에게 큰 방울, 시작 때 2개), 하트(비행기에 보호 방울: 한 번 맞아도 깜짝 없이 방울만 터짐), 사탕(별 +5).
- **대장 먹구름**(원본 Boss 3단계): 기분 막대 70% / 40% / 0%에서 공격이 바뀐다. 1단계 느린 원형 방울, 2단계 볼을 빵빵하게 하고(`boss_charge`) 부채꼴, 3단계 작은 먹구름을 불러냄. 맞으면 움찔(`boss_hit`). 기분이 0이 되면 하얀 웃는 구름(`boss_happy`)이 된다.
  - **60초가 지나면** 대장이 지쳐서 스스로 웃으며 하얀 구름이 된다("대장 먹구름이 웃었어요!"). 못 이기는 일 없이 항상 끝까지 간다.

## 난이도

적 방울의 양과 속도로 나눈다. 별 수를 비교할 수 없으므로 **난이도별 랭킹**(`flight:easy`, `flight:normal`, `flight:hard`).

| 변형 | 적 방울 쏘기 | 적 방울 속도 | 대장 기분 |
|---|---|---|---|
| 쉬움 | UFO·번개구름만, 적게 | 느림 | 적음 |
| 보통 | 쉬움의 1.5배 | 보통 | 보통 |
| 어려움 | 쉬움의 2배 | 조금 빠름 | 많음 |

- 꾸미기 속도(느림 / 보통 / 빠름)는 배경 흐름과 장난꾸러기 등장 빠르기에 곱한다(랭킹은 나누지 않음).
- 비행 구간은 Core의 등장 표(시간, 종류, 높이, 움직임)로 정해 매번 같다.

## 점수와 랭킹

- 별: 장난꾸러기를 웃게 하면 작은 먹구름·꿀벌 +1, UFO +2, 번개구름 +3, 사탕 +5, 대장 +20(지쳐서 웃으면 +10). 떨어진 별은 화면에 잠깐 남았다가 비행기 쪽으로 빨려 온다(다 먹기 쉽게).
- 랭킹: 점수 높은 순(`RankOrder.ScoreDesc`), "별 N개". 0개면 기록하지 않는다. 보조 줄: "웃게 한 친구 N명".
- 결과 화면 "모두 깨끗해졌어요!" / "모은 별" / "N개". 버튼: 다시 하기 / 꾸미기 / 메인으로.

## 연출 강도

- 방울 쏘기(가장 자주): 소리를 거의 내지 않거나 아주 작게(계속 나므로). 방울이 살짝 흔들리며 날아감.
- 장난꾸러기가 웃음: 방울이 터지며 하얀 김, 웃는 구름으로 바뀌어 둥실, "뽀잉" 소리, 별 튐.
- 아이템: 둥실 떠 오는 아이템이 반짝, 먹으면 "띠링"과 문구("방울이 세졌어요!").
- 폭죽: 화면 전체 반짝, 적 방울이 별로 바뀌어 빨려 옴, 큰 "펑-반짝".
- 대장 등장: 음악이 바뀌고 대장이 크게 들어와 볼을 부풀림. 대장이 웃을 때: 팡파르, 무지개, 색종이.

## 원본에서 바꾼 점

- **탄막 슈팅 → 아이용 비행 모험**: 적을 "파괴"하지 않고 웃게 만든다. 터짐·폭발 대신 웃는 구름과 별.
- **Life·Game Over 없음**: 맞으면 깜짝 놀라기만 하고 아무것도 잃지 않는다. 판은 항상 대장이 웃을 때까지 간다(60초 뒤 스스로 웃음).
- **자동 발사, 상대 이동 터치**: 아이는 움직이기만 하면 된다.
- **나선·교차 패턴 제외, 느리고 적은 파스텔 방울**: 화면이 무섭게 붐비지 않게.
- **세로 → 가로 횡스크롤**: 가로 화면에 맞췄다.

## 완료 조건

- 자동 발사, 키·드래그(상대 이동) 이동, 천천히 이동, 폭죽.
- 장난꾸러기 4종이 웃는 구름으로 바뀌고 별을 떨어뜨린다. 맞으면 깜짝 + 무적, 잃는 것 없음.
- 아이템 4종, 방울 레벨 1~4.
- 대장 3단계와 60초 뒤 스스로 웃기, 결과 화면, 난이도별 Top 10 기록.
- `--game=flight --autoplay` 스모크 테스트 오류 없음(`--quit-after`를 길게).

- 기획과 달라진 점
  - 아이템은 "떨어뜨림"이 아니라 정해진 시간에 오른쪽에서 둥실 떠 온다(번개는 4개: 4단계까지 3개 + 하나 놓쳐도 되게 1개). 비행기 근처(0.2)에 오면 빨려 온다. 이미 가득 찬 아이템(방울 4단계, 폭죽 5개, 보호 방울 있음)은 별 +2.
  - 쉬움은 UFO·번개구름(과 대장)만 쏜다. 보통은 꿀벌이, 어려움은 꿀벌·작은 먹구름이 지나가며 한 발씩 더 쏜다. "1.5배/2배"는 쏘는 간격으로 나눴다.
  - 폭죽이 바꾼 별은 한 번에 10개까지만 점수에 들어간다(방울이 많을 때 아껴 쓰는 게 너무 유리하지 않게). 폭죽은 친구에게 큰 방울(체력 10), 대장 기분 6%.
  - 친구 몸에 부딪혀도 방울과 같이 깜짝(친구는 그대로). 대장이 웃으면 남은 친구도 모두 웃고 적 방울은 모두 터진다. 끝날 때 아직 날아오던 별도 점수에 넣는다.
  - 친구는 화면 안으로 조금 들어온 뒤부터 맞는다(보기도 전에 웃어 버리지 않게). 체력: 작은 먹구름·꿀벌 5, UFO 12, 번개구름 26. 대장 기분 340 / 460 / 580.
  - 4단계 큰 별 방울은 줍는 별과 헷갈려서 비눗방울 안에 별이 든 모양으로 그렸다.
  - 대장 3단계도 원형 방울을 느리게 계속 쏜다(작은 먹구름 부르기 2마리 / 5초와 함께). 원형은 매번 반 칸씩 돌려 쏘지만 나선은 아니다.
  - 대장 등장 음악은 따로 없어 같은 곡을 빠르게(템포 1.12) 했다. 소리는 기존 합성음: 친구 웃음 `Jump`("보잉"), 맞힘 `Plop`, 깜짝 `Bonk`, 보호 방울 `Pop`, 아이템 `Coin`, 별 `Catch`(작게), 폭죽 `Pop`+`Cheer`+`Whoosh`, 대장 `Whoosh`+`QuestionChime`, 대장 웃음 `Fanfare`+`Cheer`. 내 방울 쏘기는 소리 없음.
  - 꾸미기에는 난이도와 속도만 둔다(배경 선택 없음, 응원 친구 없음).
- 자동 플레이: `FlightBot`이 가장 가까운 친구(대장)와 높이를 맞추고, 아이템이 오면 그쪽으로 가고, 0.7초 안에 0.1보다 가까이 지나갈 방울은 피한다. 28초마다 2.5초 동안 피하지 않고 가장 가까운 방울로 가서 일부러 맞아 본다. 방울이 많아지면(쉬움 8, 그 외 12개) 폭죽을 한 번 쓴다. 헤드리스 자동 플레이만 3배속(`Engine.TimeScale = 3`)이라 `--quit-after 8000` 안에 결과·기록까지 간다.
