# 네모 나누기

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 5절(Shikaku). 게임 방식만 가져오고 아이용으로 바꿨다.

## 게임 목표

판을 네모 조각으로 나눈다. 조각마다 숫자가 딱 하나 들어 있고, 조각의 칸 수가 그 숫자와 같아야 한다. 판 전체를 빈틈없이 나누면 완성.

## 게임 플로우

`꾸미기(난이도 → 배경 → 응원 친구) → 판과 숫자 배지가 톡톡 나타남 → 끌어서 네모 그리기 → … → 판을 다 덮음 → "완성!" → 결과 화면`

- 시간 제한 게임이 아니어서 카운트다운이 없다. 시계는 첫 입력부터 간다(작고 옅게).

## 조작

- 터치: 한 칸을 누르고 끌면 누른 칸과 손가락 칸을 꼭짓점으로 하는 네모가 점선(`shikaku/drag_frame.png`)으로 그려지고, 떼면 확정을 시도한다. 그리는 동안 네모 옆에 지금 칸 수("6칸")가 따라다닌다.
- 놓인 조각을 짧게 누르면 조각이 지워진다.
- PC: 마우스는 터치와 같이 동작. 입력은 터치 이벤트만 처리한다.
- 되돌리기(`ui/undo.png`)와 처음부터(`ui/reset.png`) 버튼.

## 화면 구조

- 가운데에 정사각형 판(1280x720에서 4x4는 칸 약 140px, 7x7은 약 85px). 왼쪽 패널: 그만하기, 시계. 오른쪽 패널: 되돌리기, 처음부터, 힌트(`ui/hint.png`), 응원 친구.
- 숫자는 칸 가운데 동그란 배지(`shikaku/clue_badge.png`) 위에 굵게.

## 규칙과 판정

- 떼는 순간 네모를 검사한다(원본 판정 그대로).
  - 숫자 1개, 칸 수 = 숫자 → **놓임**: 조각이 파스텔 색(`shikaku/region_fill.png`에 색을 입힘)으로 채워진다. 이미 있던 조각과 겹치면 겹친 옛 조각은 지워진다.
  - 숫자 0개, 2개 이상, 칸 수가 다름 → **놓이지 않음**: 점선 네모가 살짝 흔들리며 사라지고, 칸 수 글자가 숫자 쪽으로 "6칸 → 4칸이 필요해요"처럼 짧게 알려 준다(숫자가 하나일 때). 붉은 표시·감점 없음.
- 1칸짜리 네모(숫자 1)는 그 칸을 짧게 누르기만 해도 놓인다.
- 원본처럼 "정답 조각"과 비교하지 않는다. 규칙에 맞으면 어떤 조각이든 놓이고, 판 전체를 덮으면 완성이다. 막히면 조각을 지우거나 되돌려 다시 한다.
- **힌트(전구)**: 정답 조각 하나가 점선으로 반짝인다. 누르면 그 자리에 놓인다. 감점 없음, 보조 줄에 "힌트 N번"만.

## 난이도

**난이도별 랭킹**(`shikaku:easy`, `shikaku:normal`, `shikaku:hard`).

| 변형 | 판 | 숫자 크기 |
|---|---|---|
| 쉬움 | 4x4 | 1~6 |
| 보통 | 5x5 | 1~8 |
| 어려움 | 7x7 | 1~10 |

- 원본은 5x5 / 7x7 / 10x10이지만, 10x10은 칸이 작아(약 60px) 아이 손가락으로 끌기 어려워 한 단계씩 줄였다.
- 문제는 Core 생성기가 시드에서 판을 무작위 네모로 나눠 만든다(답 하나뿐 확인). 난이도마다 미리 고른 시드 10개, "다음 문제"로 차례로 돈다. 같은 난이도의 문제들은 한 표를 같이 쓴다.

## 점수와 랭킹

- 랭킹: 걸린 시간 짧은 순(`RankOrder.TimeAsc`). 끝까지 하면 기록 대상. 힌트는 기록에 영향 없이 보조 줄에만.
- 결과 화면: "완성!" / "걸린 시간" / "N.N초" / "힌트 N번"(0번이면 "힌트 없이 했어요!"). 버튼: 다음 문제 / 다시 하기 / 메인으로.

## 연출 강도

- 끌기(자주): 점선 네모가 칸에 딱딱 붙으며 커지고, 칸이 바뀔 때 아주 작은 "틱". 칸 수가 숫자와 같아지면 점선이 밝아진다.
- 조각 놓임: 색이 퍼지듯 채워지고 배지가 깡충, "뿅"(놓인 조각 수에 따라 음이 올라감).
- 완성: 조각들이 차례로 반짝이며 판 전체가 무지개 물결, 팡파르, 색종이.

## 원본에서 바꾼 점

- **"실패" 판정 → 놓이지 않음**: 흔들리며 사라지고, 필요한 칸 수를 알려 준다. 붉은 표시 없음.
- **10x10 → 7x7까지**: 아이 손가락에 맞게.
- **규칙에 맞으면 어떤 조각이든 허용**: 정답과 달라도 막지 않고 스스로 고칠 수 있게. 되돌리기·처음부터·힌트로 막힘을 푼다.

## 사용 리소스

- `shikaku/clue_badge.png`, `shikaku/region_fill.png`(9-slice, 게임에서 파스텔 색), `shikaku/drag_frame.png`(9-slice), `ui/cell_empty.png`, `ui/undo.png`, `ui/reset.png`, `ui/hint.png`, `ui/board_frame.png`, `menu/shikaku.png`. 배경 기본 `backgrounds/garden.png`.
- **리소스가 없을 때**: 배지는 흰 원 + 테두리, 조각은 둥근 사각형(`StyleBoxFlat` 또는 `_Draw`), 점선은 `_Draw`로 그린다.

## 구현 메모

- `scripts/Core/ShikakuRules.cs`: 판 생성(무작위 네모 분할 → 조각마다 숫자 한 칸, 답 하나뿐 검사, 자체 난수로 결정적), 네모 판정(숫자 수, 칸 수), 조각 놓기/지우기/겹침 처리, 완성 판정, 힌트 조각. 단위 테스트 `ShikakuRulesTests`(모든 시드 답 하나, 완성 판정, 첫 문제 모양 고정).
- `scripts/Games/Shikaku/`: 씬 `scenes/games/shikaku.tscn`. 공통: `GameCatalog`에 `shikaku`(변형 `ShikakuRules.Variants`), `ResultPanel`, `QuitConfirm`, `Buddy`. 설정 `[shikaku]`(`level`, `next_*`, `scenery`, `buddy`).
- 개발용 `--autoplay`: 정답 조각을 1초 간격으로 끌어서 그린다. 가끔 칸 수가 다른 네모를 먼저 그려 본다.

## 완료 조건

- 끌어서 네모 그리기, 칸 수 표시, 놓임/놓이지 않음 판정.
- 조각 지우기, 겹치면 옛 조각 지움, 되돌리기, 처음부터, 힌트.
- 판 전체를 덮으면 완성 → 결과 화면, 난이도별 Top 10 기록.
- 생성 문제가 모두 답 하나뿐(단위 테스트). `--game=shikaku --autoplay` 스모크 테스트 오류 없음.

- 기획과 달라진 점
  - 문제: 생성기 + 난이도마다 시드 10개(101~110, 201~210, 301~310). 답 하나뿐에 더해 1칸 조각은 판마다 최대 하나(공짜라서), 조각 수는 4x4 4~6개 / 5x5 5~8개 / 7x7 8~12개, 가장 큰 숫자가 그 난이도 최대값-2 이상.
  - 화면: 왼쪽 그만하기·"어려움 · 2번 문제"·작은 시계("끌면 시계가 가요" → "N초"). 오른쪽 되돌리기·처음부터·힌트(세로), 오른쪽 아래 응원 친구. 칸 크기 1280x720에서 4x4 140px, 5x5 112px, 7x7 85px.
  - 끌기: 점선 네모가 칸에 붙어 커지고, 칸이 바뀔 때 `Tick`(칸 수에 따라 조금씩 높게), 칸 수가 숫자와 같아지면 점선이 초록으로 밝아지고 높은 틱. "N칸" 글자는 네모 오른쪽 아래(화면 밖이면 왼쪽). 판 밖으로 끌면 가장자리 칸에 머문다.
  - 놓임: 조각이 가운데서 퍼지며 파스텔 색(숫자마다 정해진 색), 배지 깡충, `Pop(놓인 조각 수)`(올라가는 뿅), 별 몇 개. 놓이지 않음: 점선이 살짝 흔들리며 사라지고 "통"(`WallBump`)과 약한 진동, 숫자 배지가 도리도리, 글자 "6칸 → 4칸이 필요해요"(숫자 하나일 때), "숫자를 하나 넣어 그려요"(숫자 없음), "숫자는 하나만 넣어요"(숫자 여럿). 흰 글자 + 진한 테두리, 붉은색 없음.
  - 짧게 누르기: 조각 위면 지우기, 빈 1 칸이면 놓기, 다른 숫자 칸이면 배지 도리도리 + "끌어서 N칸 네모를 그려요".
  - 힌트: 아직 없는 정답 조각 중 아이가 놓은 조각과 안 겹치는 것을 먼저, 그중 그릴 방법이 가장 적은 숫자(가장 알아보기 쉬운 것)를 골라 금색 점선으로 세 번 깜빡인 뒤 놓는다(기획의 "누르면 그 자리에 놓인다"를 힌트 버튼 한 번으로 처리). 감점 없음, 보조 줄 "힌트 N번". 힌트로 놓인 조각도 보통 조각처럼 지우거나 되돌릴 수 있다.
  - 처음부터: 모든 조각을 빼고, 되돌리기로 한 번에 되살릴 수 있다.
  - 완성: 조각들이 대각선 순서로 무지개색으로 반짝이며 커졌다 돌아오고 배지 깡충·별, `Fanfare`, 색종이, "완성!", 친구 "다 했다!".
  - PC 키: 방향키·WASD로 주황 커서 이동, Space/Enter로 네모 시작 → 커서 이동 → 다시 Space/Enter로 놓기, Esc 취소, Delete/Backspace 커서 칸 조각 지우기, Z/U 되돌리기, R 처음부터, H 힌트.
  - 배경은 공용 `Scenery`(기본 공원)라 `garden.png`(기획서 기본 배경)는 쓰지 않았다(스도쿠와 같은 판단). `ui/board_frame.png`는 사용.
- 자동 플레이(`--autoplay`)
  - 다음 힌트 조각(정답 조각)을 한쪽 꼭짓점 → 가운데 → 반대 꼭짓점으로 끌어서 놓는다(약 1.4초에 한 조각). 첫 조각과 세 번째마다 한 칸 넓은 틀린 네모를 먼저 그려 본다. 앞쪽에서 한 번씩 조각 눌러 지우기 → 다시 그리기, 그리고 되돌리기 → 힌트, 처음부터 → 되돌리기를 지나간다.
  - 배속 없이 8000프레임 안에 끝난다(시계 기준 쉬움 약 15초, 보통 약 18초, 어려움 약 26초 + 결과 화면).
