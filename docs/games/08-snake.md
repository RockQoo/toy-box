# 애벌레 냠냠

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 추가 추천 9절(Snake). 게임 방식만 가져오고 아이용으로 바꿨다.

## 게임 목표

칸 위를 기어가는 애벌레의 방향을 바꿔 잎사귀를 먹는다. 잎을 먹을수록 애벌레가 길어진다. 60초 동안 잎을 최대한 많이 먹는다.

## 게임 플로우

`꾸미기(배경 → 응원 친구 → 속도) → 3·2·1 카운트다운 → 60초 플레이 → "끝!" → 결과 화면`

- 시간 제한 게임 공용 구성: `Countdown`, `RoundHud`(점수·그만하기·남은 시간+`TimerBar`·단계 문구·"끝!").
- 판 시작 때 애벌레는 가만히 있고 "방향을 눌러요!"가 깜박인다. 첫 입력부터 기어간다(시계는 카운트다운 뒤부터 간다).

## 조작

- PC: 방향키 또는 WASD. 진행 방향의 정반대 입력은 무시한다(제자리 뒤돌기 없음).
- 터치: 판 위에서 스와이프(칸 크기의 40%를 끌면 방향 결정). 오른쪽 아래에 큰 방향 버튼(`ui/btn_up/down/left/right.png`, 미로 탈출과 같은 배치 ▲ / ◀ ▼ ▶)도 둔다.
- 입력은 터치 이벤트만 처리한다. 한 칸 이동 사이에 들어온 입력은 두 개까지 줄을 세워 두어(빠르게 ㄱ자로 꺾기) 놓치지 않는다.

- 가로 화면에 맞는 장르라 판도 가로로 길다: 16 x 9칸(1280x720에서 칸 약 64px). 오른쪽 아래 방향 버튼 자리를 비우도록 판을 왼쪽으로 붙인다.

## 규칙과 판정

- 애벌레는 일정 간격(속도 단계)마다 한 칸씩 진행 방향으로 움직인다.
- 잎은 판 위에 항상 1개(30초 이후 2개). 머리가 잎 칸에 들어가면 먹고 +1, 몸이 한 칸 길어지고, 애벌레가 없는 빈 칸에 새 잎이 난다.
- **벽에 닿으면**: 원본은 게임 끝이지만, 여기서는 애벌레가 벽 앞에서 멈추고 "깜짝"(머리가 살짝 뒤로 튀고 작은 "통" 소리) 한 뒤 새 방향 입력을 기다린다. 감점 없음, 시간만 흐른다.
- **자기 몸에 닿으면**: 원본은 게임 끝이지만, 여기서는 **자기 몸을 지나갈 수 있다**(머리가 몸 위로 기어 넘어가는 모습). 길이가 길어져도 갇히지 않는다.
- 몸 길이는 최대 40칸(그 뒤로는 잎을 먹어도 점수만 오른다). 판이 꽉 차는 일을 막는다.

## 난이도

- 시간이 갈수록 빨라진다(초당 칸 수, 속도 "보통" 기준): 0~20초 4칸 → 20~40초 5칸 → 40~60초 6칸. 단계가 바뀌면 "빨라져요!" 문구와 음악이 조금 빨라진다.
- 꾸미기의 속도(느림 / 보통 / 빠름, 공용 `StartSpeed`)를 곱한다. 풍선·과일처럼 꾸미기 옵션이므로 랭킹은 나누지 않는다.

## 점수와 랭킹

- 잎 하나 +1. 반짝이는 황금 잎(10초 이후 가끔, 6초 뒤 사라짐)은 +3.
- 랭킹: 점수 높은 순(`RankOrder.ScoreDesc`), "잎 N개". 0개면 기록하지 않는다. 보조 줄: "가장 길 때 N칸".
- 결과 화면 버튼: 다시 하기 / 꾸미기 / 메인으로.

## 연출 강도

- 이동(가장 자주): 몸이 꿈틀꿈틀 물결처럼 앞뒤로 늘었다 줄어든다. 소리 없음(음악만).
- 잎 먹기: 머리가 입을 벌렸다 닫고(`head_eat`), "냠" 소리(연속으로 먹으면 음이 올라감), 잎 조각과 "+1". 몸에 먹은 자리가 볼록하게 꼬리까지 전달된다.
- 10개마다: 반짝 소리, 애벌레 몸이 무지개로 한 번 물결, 친구 응원.
- 시간 끝: 애벌레가 동그랗게 몸을 말며 웃는다 → "끝!".

## 원본에서 바꾼 점

- **벽·몸 충돌로 끝나지 않는다**: 벽은 멈춤 + 깜짝, 몸은 지나가기. 실패 연출 없이 시간 끝까지 즐긴다.
- **시간 제한 60초 + 점수**: 끝을 실패가 아닌 시간으로 정해 다른 시간 제한 게임과 같은 흐름으로 맞췄다.
- **가로 판**: 가로 화면에 맞춰 16 x 9.

## 완료 조건

- 키, 스와이프, 방향 버튼으로 방향을 바꾼다. 정반대 입력은 무시된다.
- 잎을 먹으면 길어지고 점수가 오른다.
- 벽에서 멈췄다가 새 방향으로 다시 간다. 몸은 지나갈 수 있다.
- 60초 뒤 "끝!" → 결과 화면, Top 10 기록.
- `--game=snake --autoplay` 스모크 테스트에서 런타임 오류가 없다.

### 기획과 달라진 점

- **멈춰 있을 때는 정반대 방향도 받는다**: 움직이는 동안은 기획대로 정반대 입력을 무시하지만, 첫 입력 전과 벽에 멈춘 뒤에는 어느 방향이든 받는다. 벽 앞에서 아이가 "뒤로"를 눌렀는데 아무 일도 안 일어나면 막힌 것처럼 느껴지기 때문(몸은 지나갈 수 있으므로 문제없다).
- **방향 버튼**: 미로의 `DirPad`(코드로 그린 화살표)를 재사용하지 않고 기획서대로 `ui/btn_up/down/left/right.png` 그림 버튼을 쓴 `SnakePad`를 새로 만들었다. 누르는 순간 방향이 바뀌고, 키·스와이프·자동 플레이로 바꿀 때도 해당 버튼이 살짝 눌린다.
- **몸 모서리 그림(`body_corner.png`)은 쓰지 않았다**: 몸은 칸 사이를 미끄러지듯 보간해서 움직이므로 동그란 마디(`body.png`)를 이어 그리는 편이 모퉁이에서도 자연스럽다.
- **머리 방향**: 머리 그림은 위·아래로 90도 돌리면 얼굴이 옆으로 눕기 때문에, 왼쪽/오른쪽을 보는 그림(왼쪽은 좌우 반전)을 위·아래로 최대 약 50도만 기울인다.
- **황금 잎**: 그림이 따로 없어 `leaf.png`를 셰이더로 금빛으로 바꾸고 빛 무리와 반짝이를 그린다. 10초부터 7~12초 간격으로 나오고 6초 뒤 사라진다(마지막 2초는 깜박임). 나타날 때 `QuestionChime`.
- **잎 위치**: 빈 칸 중 머리에서 3칸 이상 떨어진 곳(없으면 아무 빈 칸).
- **입 벌리기**: 먹을 때뿐 아니라 바로 앞 칸에 잎이 있을 때도 `head_eat`로 입을 벌린다. 끝날 때 몸을 동그랗게 말 때도 웃는 얼굴(`head_eat`).
- **효과음**: 기존 합성음만 썼다. 냠 = `Catch(연속)`(2.5초 안에 이어 먹으면 음이 올라감), 벽 = `WallBump`, 황금 잎 = `Coin`, 10개마다 = `Cheer`.
- **점수판 글자**: 공용 `RoundHud`라 "잎 12"가 아니라 잎 아이콘 + "점수 12"로 나온다(과일 받기와 같은 방식). 랭킹 표에는 "잎 N개".

### 자동 플레이

- 꾸미기 1.2초 뒤 시작 → 카운트다운 뒤 0.7초 기다렸다가(“방향을 눌러요!”가 보이게) 황금 잎을 먼저, 없으면 가장 가까운 잎을 향해 최단 방향으로 꺾는다(정반대가 필요하면 옆으로 한 칸 비켜 돈다).
- 14초부터 15초마다 한 번은 방향을 바꾸지 않고 벽까지 가서 "깜짝"(멈춤 → 새 방향) 경로를 돈다.
- 60초 판이라 헤드리스 스모크 테스트(약 140프레임/초, 8000프레임에서 종료)에서는 `Engine.TimeScale = 2`로 두 배 빠르게 돌린다(`--autoplay` + 헤드리스일 때만, 씬을 나가면 1로 되돌림). `--write-movie` 화면 확인과 실제 플레이는 보통 속도.
