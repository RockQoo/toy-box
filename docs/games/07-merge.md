# 숫자 합치기

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 3절(2048). 게임 방식만 가져오고 아이용으로 바꿨다.

## 게임 목표

판 위의 숫자 타일을 한쪽으로 밀어 같은 숫자끼리 합친다. 2 → 4 → 8 … 점점 큰 숫자를 만들어 점수를 모은다. 더 이상 밀 곳이 없으면 판이 끝난다.

## 게임 플로우

`꾸미기(판 크기 → 배경 → 응원 친구) → 타일 2개가 톡 튀어나옴 → 밀기 → 합치기 → 새 타일 → … → 더 못 움직임 → "끝!" → 결과 화면`

- 시간 제한 게임이 아니어서 카운트다운이 없다. 시간은 재지 않는다.
- 플레이 중 "그만하기"는 다른 게임처럼 "정말 그만할까요?"를 묻는다(그만하면 기록하지 않음).

## 조작

- PC: 방향키 또는 WASD(물리 키라 한글 입력 상태에서도 됨). 키 한 번에 한 번 민다.
- 터치: 판 위에서 스와이프. 손가락을 뗄 때가 아니라 일정 거리(칸 크기의 30%)를 끌면 바로 민다. 한 번 누른 동안에는 한 번만 민다.
- `emulate_touch_from_mouse`가 켜져 있으므로 마우스 드래그도 같은 스와이프로 들어온다. 입력은 터치 이벤트(`InputEventScreenTouch`/`ScreenDrag`)만 처리한다.
- 밀고 있는 애니메이션(약 0.12초) 중에 들어온 입력은 하나 기억했다가 바로 처리한다.

## 화면 구조

```text
┌──────────┬──────────────────┬──────────┐
│ 그만하기 │                  │ 점수 128 │
│          │   ┌──┬──┬──┬──┐  │ 최고  64 │
│  (배경)  │   │ 2│  │ 4│  │  │          │
│          │   ├──┼──┼──┼──┤  │ [되돌리기]│
│          │   │  │ 8│  │ 2│  │   x3     │
│          │   └──┴──┴──┴──┘  │   친구   │
└──────────┴──────────────────┴──────────┘
```

- 1280x720 기준 가운데에 정사각형 판(높이의 약 85%), 오른쪽 열에 점수, 이번 판에 만든 가장 큰 타일, 되돌리기 버튼. 응원 친구는 오른쪽 아래.
- 판 크기는 `GetViewportRect().Size`에서 매번 계산한다.

## 규칙과 판정

- 원본 규칙 그대로: 한 방향으로 밀면 타일이 끝까지 미끄러지고, 맞닿은 같은 숫자는 하나로 합쳐진다. **한 번 밀 때 한 타일은 한 번만 합쳐진다**(`2 2 2 .` → `4 2 . .`, `2 2 2 2` → `4 4 . .`).
- 실제로 움직인 타일이 있을 때만 새 타일이 빈 칸 하나에 생긴다(2가 90%, 4가 10%).
- 아무 타일도 움직이지 않는 방향으로 밀면 판이 그 방향으로 살짝 출렁이고 작은 "통" 소리만 난다(새 타일 없음).
- **되돌리기**: 판마다 3번. 바로 전 상태로 돌아간다(점수도 함께). 아이가 실수로 민 것을 되돌릴 수 있게 한다.
- **끝**: 빈 칸이 없고 상하좌우로 붙은 같은 숫자도 없으면 끝. 되돌리기가 남아 있으면 바로 끝내지 않고 친구가 "되돌려 볼까?"라고 하며 되돌리기 버튼이 흔들린다. 아이가 "끝내기"를 누르거나 되돌리기를 다 쓰면 "끝!" → 결과 화면.
- **2048 완성**: 원본의 "계속하기/종료" 창 대신 축하 연출만 하고 계속한다(아이가 고를 필요가 없게). 아이에게는 2048이 멀기 때문에 128, 256, 512, 1024, 2048을 처음 만들 때마다 단계 축하를 한다.

## 난이도

판 크기로 나눈다. 점수를 비교할 수 없으므로 **난이도별 랭킹**(`merge:easy`, `merge:normal`).

| 변형 | 판 | 특징 |
|---|---|---|
| 쉬움 | 5x5 | 칸이 많아 오래 할 수 있다 |
| 보통 | 4x4 | 원본 그대로 |

판이 클수록 쉽다(막히기 어렵다). 3x3은 너무 빨리 막혀서 넣지 않는다.

## 점수와 랭킹

- 원본 그대로 합쳐서 만든 숫자를 점수에 더한다(2+2 → +4).
- 랭킹: 점수 높은 순(`RankOrder.ScoreDesc`). 결과 화면 보조 줄(`ResultSpec.Detail`)에 "가장 큰 타일 256".
- 결과 화면: "끝!" / "점수" / "N점"(count-up) / "가장 큰 타일 N". 버튼: 다시 하기 / 꾸미기 / 메인으로.

## 연출 강도

- 밀기(가장 자주): 타일이 미끄러지고 벽에 닿을 때 살짝 찌그러짐, 가벼운 "슥".
- 합치기: 합쳐진 타일이 튀어 오르며 커졌다 돌아옴, 숫자에 따라 음이 올라가는 "뿅", 작은 별 몇 개, 타일 위 "+8".
- 새 단계 타일(128 이상 처음): 반짝 소리, 별 소나기, "128 만들었다!" 문구, 친구 응원.
- 끝: 판 전체가 물결처럼 한 번 뛰고 "끝!", 약 1.5초 뒤 결과 화면.

## 원본에서 바꾼 점

- **게임오버 → "끝!"**: 막힌 것을 실패로 보여 주지 않는다. 되돌리기 3번으로 다시 시도할 기회를 주고, 끝은 축하로 마무리한다.
- **승리 창 없음**: 2048을 만들어도 고르는 창 없이 축하만 하고 계속한다.
- **중간 목표**: 2048은 아이에게 너무 멀어 128부터 단계마다 축하한다.
- **쉬움(5x5) 추가**: 아이가 오래 즐길 수 있게.

## 사용 리소스

- `merge/tile_01.png` ~ `merge/tile_12.png`(2 ~ 4096, 단계마다 색과 장식). 숫자는 게임에서 굵은 한글 글꼴로 올린다. 4096을 넘는 타일은 `tile_12`를 쓴다.
- `ui/board_frame.png`, `ui/board_bg.png`, `ui/cell_empty.png`(판), `ui/undo.png`(되돌리기), `menu/merge.png`(메뉴 카드), `backgrounds/playroom.png`(기본 배경).
- **리소스가 없을 때**: 타일은 코드로 둥근 사각형을 그린다(단계별 파스텔 → 진한 색 → 금색, 128 이상은 테두리 빛). 판은 `UiTheme` 패널 색, 배경은 공용 `Scenery`.

## 구현 메모

- `scripts/Core/MergeRules.cs`: 판 상태(`int[,]`), 한 방향 밀기(이동·합치기 결과와 각 타일의 출발/도착 칸, 움직였는지), 새 타일(난수 주입), 끝 판정, 되돌리기 기록. `using Godot` 없이 단위 테스트(`MergeRulesTests`: 이중 합체 없음, 움직임 없으면 새 타일 없음, 끝 판정).
- `scripts/Games/Merge/`: 씬 `scenes/games/merge.tscn`(루트 하나), 판·타일 노드는 `_Ready`에서 코드로 만든다. 타일 이동은 Core 결과의 출발/도착 칸으로 트윈.
- 공통: `GameCatalog`에 `merge` 추가(변형 `MergeRules.Variants`), `ResultPanel`, `QuitConfirm`, 응원 `Buddy`. 설정은 `settings.cfg`의 `[merge]`(`size`, `scenery`, `buddy`).
- 개발용 `--autoplay`: 빈 칸이 가장 많이 남는 방향을 고르는 단순한 탐욕 플레이.

## 완료 조건

- 네 방향 키와 스와이프로 밀 수 있다.
- 한 번에 한 타일은 한 번만 합쳐진다(단위 테스트).
- 움직임이 있을 때만 새 타일이 생긴다.
- 되돌리기 3번이 동작하고, 막혔을 때 되돌리기를 권한다.
- 막히면 "끝!" → 결과 화면, 변형별 Top 10에 기록된다(0점은 기록 안 함).
- `--game=merge --autoplay` 스모크 테스트에서 런타임 오류가 없다.
