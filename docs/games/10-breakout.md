# 벽돌깨기

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 추가 추천 16절(고전 벽돌깨기). 게임 방식만 가져오고 아이용으로 바꿨다.

## 게임 목표

구름 받침판으로 공을 튕겨 위쪽 벽돌을 깬다. 60초 동안 벽돌을 최대한 많이 깬다. 판의 벽돌을 다 깨면 새 벽돌 판이 내려온다.

## 게임 플로우

`꾸미기(배경 → 응원 친구 → 속도) → 3·2·1 카운트다운 → 공이 받침판 위에서 자동 출발 → 60초 플레이 → "끝!" → 결과 화면`

- 시간 제한 게임 공용 구성(`Countdown`, `RoundHud`, `TimerBar`).

## 조작

- 터치: 판 어디든 누르고 끌면 받침판이 손가락의 x를 부드럽게 따라간다(과일 받기 바구니와 같은 방식). 받침판을 손가락으로 가리지 않아도 된다.
- PC: ← → / A D. 마우스는 `emulate_touch_from_mouse`라 누르고 끌 때 터치와 같이 동작한다.
- 공이 받침판 위에 얹혀 있을 때는 1초 뒤 자동으로 출발한다(누르면 바로 출발).

## 화면 구조

```text
┌──────────┬────────────────────┬──────────┐
│ 그만하기 │ ▭▭▭▭▭▭▭▭▭▭        │ 벽돌 23  │
│          │ ▭▭▭▭▭▭▭▭▭▭        │          │
│  (배경)  │                    │ 남은 시간│
│          │        ●           │   ▬▬▬    │
│          │                    │          │
│          │      ☁☁☁☁          │   친구   │
└──────────┴────────────────────┴──────────┘
```

- 원래 세로 장르라 **가운데에 세로 판**(화면 높이 전체, 폭은 높이의 0.75배, 1280x720에서 540x720), 양옆은 배경과 패널. 왼쪽 패널에 그만하기, 오른쪽 패널에 점수·남은 시간 막대·응원 친구.

## 규칙과 판정

- 공은 일정 속도로 직선 이동, 판의 좌우 벽과 위쪽에서 튕긴다. 받침판에 맞은 위치에 따라 튕기는 각도가 바뀐다(가운데는 위로, 끝은 비스듬히, 최대 60도). 너무 수평으로 가지 않게 각도 최소값을 둔다.
- 벽돌 단계 1~3: 단계 수만큼 맞아야 깨진다(맞을 때마다 한 단계 낮은 색으로). 깨면 +1.
- **공을 놓치면**: 원본은 Life가 줄지만, 여기서는 공이 바닥 꽃줄에 "퐁" 하고 닿아 작은 방울이 되어 받침판 위로 날아와 다시 얹힌다(1초 뒤 자동 출발). 감점·목숨 없음, 시간만 흐른다.
- **판을 다 깨면**: "다 깼다!" 축하 후 새 벽돌 판이 위에서 내려온다(판 모양 5종 순서대로, 판마다 단계가 조금 높음). 공은 받침판 위에서 다시 출발.
- 받침판은 그림보다 판정 폭을 넉넉하게(그림 폭의 115%).

## 난이도

- 시간이 갈수록 공이 조금씩 빨라진다(화면 높이/초, 속도 "보통" 기준): 0~20초 0.70 → 20~40초 0.80 → 40~60초 0.90. 단계 문구 "빨라져요!".
- 꾸미기 속도(느림 / 보통 / 빠름, 공용 `StartSpeed`)를 공 속도에 곱한다. 다른 시간 제한 게임처럼 랭킹은 나누지 않는다.
- 아이템(확장): 공 늘리기(`brick/item_ball_add.png`)가 가끔 떨어진다. 받으면 공이 3개로 나뉜다. 첫 버전은 아이템 없이 시작해도 된다.

## 점수와 랭킹

- 벽돌 하나 깰 때 +1(단계가 높은 벽돌도 +1). 랭킹: 점수 높은 순(`RankOrder.ScoreDesc`), "벽돌 N개". 0개면 기록하지 않는다. 보조 줄: "다 깬 판 N개".
- 결과 화면 버튼: 다시 하기 / 꾸미기 / 메인으로.

## 연출 강도

- 튕김(가장 자주): 받침판이 살짝 눌렸다 돌아옴, 벽은 작은 "톡".
- 벽돌 맞힘(단계만 내려감): 금 간 자국(`crack_1/2`)이 생기고 살짝 흔들림, "똑".
- 벽돌 깨짐: 벽돌 색 조각(`Shards`)과 별, "+1", 연속으로 깨면 음이 올라가는 "땡".
- 판 다 깸: 팡파르, 색종이, "다 깼다!", 친구 환호.

## 원본에서 바꾼 점

- **Life 없음**: 공을 놓쳐도 받침판으로 돌아와 다시 시작. 실패 연출 없이 시간 끝까지 즐긴다.
- **스테이지 → 60초 점수 모드**: 판 모양이 달라도 기록을 비교할 수 있고, 다른 시간 제한 게임과 흐름이 같다. 다 깨면 새 판이 내려와 계속 신난다.
- **빨간 벽돌 없음**: 벽돌 색은 연두 → 하늘 → 파랑 → 보라 → 분홍 → 금색.

## 사용 리소스

- `brick/brick_1.png` ~ `brick_6.png`(벽돌 색), `brick/crack_1.png`, `crack_2.png`, `brick/ball.png`, `brick/ball_glow.png`, `brick/paddle.png`(구름 받침판), `brick/floor_line.png`(바닥 꽃줄), `brick/item_ball_add.png`, `ui/board_frame.png`, `ui/panel.png`, `menu/breakout.png`. 배경 기본 `backgrounds/playroom.png`(없으면 공용 `Scenery`).
- **리소스가 없을 때**: 벽돌은 둥근 사각형 + 윗면 밝은 줄, 받침판은 흰 원 여러 개를 겹친 구름, 공은 흰 원 + 하이라이트, 바닥은 점선 꽃줄.
- 공 늘리기 아이템과 금 간 자국은 스와이프 벽돌깨기(12번)와 같이 쓴다.

## 완료 조건

- 받침판으로 공을 튕기고, 맞은 위치에 따라 각도가 바뀐다.
- 벽돌 단계가 줄고 0이면 깨진다. 판을 다 깨면 새 판이 내려온다.
- 공을 놓쳐도 받침판으로 돌아와 계속한다.
- 60초 뒤 "끝!" → 결과 화면, Top 10 기록.
- `--game=breakout --autoplay` 스모크 테스트 오류 없음.

- 기획과 달라진 점

  - "연속으로 깨면 음이 올라가는 땡"은 공이 받침판에 닿기 전까지 깬 수로 센다(`PassTick` 음).
  - 소리: 벽 "톡" `Step`, 받침판 `WallBump`, 단계만 내려감 `Click`, 깨짐 `PassTick`, 놓침 `Plop`+`Whoosh`, 판 다 깸 `Fanfare`, 아이템 등장 `QuestionChime`·받기 `Coin`.
  - 받침판 폭은 판 폭의 약 29%(그림 0.22, 판정은 115%).
- 자동 플레이(`--autoplay`): 받침판이 떨어지는 공의 착지 x(벽 반사 계산)를 따라가되 맞히는 위치를 매번 바꿔 각도가 달라지게 한다. 내려오는 공이 없으면 아이템을 쫓는다. 14초부터 20초마다 한 번 일부러 반대쪽으로 가 공을 놓쳐 본다. 헤드리스에서만 2배속. 스모크에서 약 25~40개를 깨고 판 하나 이상을 다 깬다.
