# 숫자 / 색깔 퀴즈

## 게임 목표

화면에 표시되는 짧은 문제를 보고 올바른 답을 터치한다.

## 게임 플로우

`문제 종류 선택 → 문제 등장 → 선택지 등장 → 정답 선택 → 피드백 → 다음 문제 → 10문제 완료 → 결과 화면`

## 색깔 문제

문제:

```text
빨간 공을 눌러주세요!
```

선택지:

```text
파랑      빨강      노랑      초록
```

정답을 선택하면:

- “딩동댕!” 효과음
- 별 애니메이션
- 점수 +1
- 잠시 후 다음 문제

오답을 선택하면:

```text
한 번 더 찾아볼까요?
```

정답을 알려주지 않고 다시 선택할 수 있도록 한다.

## 숫자 문제

예:

```text
숫자 3을 찾아주세요!
```

선택지:

```text
1     5     3     7
```

## 개수 문제 확장

예:

```text
사과가 3개 있는 그림을 찾아주세요!
```

숫자 인식뿐 아니라 개수 세기 문제로도 확장할 수 있다.

## 문제 수

한 판 기본:

**10문제**

## 난이도

### 쉬움
- 선택지 2개

### 보통
- 선택지 4개

### 어려움
- 선택지 6개

## 문제 종류

- 색깔 찾기
- 숫자 찾기
- 같은 그림 찾기
- 개수 찾기

초기 버전은 색깔과 숫자만 구현하는 것을 권장한다.
