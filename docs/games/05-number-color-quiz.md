# 숫자 / 색깔 퀴즈

## 게임 목표

화면에 표시되는 짧은 문제를 보고 올바른 답을 터치한다.

## 게임 플로우

`문제 종류 선택 → 문제 등장 → 선택지 등장 → 정답 선택 → 피드백 → 다음 문제 → 10문제 완료 → 결과 화면`

## 색깔 문제

문제:

```text
빨간 공을 눌러주세요!
```

선택지:

```text
파랑      빨강      노랑      초록
```

정답을 선택하면:

- “딩동댕!” 효과음
- 별 애니메이션
- 점수 +1
- 잠시 후 다음 문제

오답을 선택하면:

```text
한 번 더 찾아볼까요?
```

정답을 알려주지 않고 다시 선택할 수 있도록 한다.

## 숫자 문제

예:

```text
숫자 3을 찾아주세요!
```

선택지:

```text
1     5     3     7
```

## 개수 문제 확장

예:

```text
사과가 3개 있는 그림을 찾아주세요!
```

숫자 인식뿐 아니라 개수 세기 문제로도 확장할 수 있다.

## 문제 수

한 판 기본:

**10문제**

## 난이도

### 쉬움
- 선택지 2개

### 보통
- 선택지 4개

### 어려움
- 선택지 6개

## 문제 종류

- 색깔 찾기
- 숫자 찾기
- 같은 그림 찾기
- 개수 찾기

초기 버전은 색깔과 숫자만 구현하는 것을 권장한다.

## 결과 화면

```text
10문제 중
9문제를 맞혔어요!

별 9개 획득!

[다시 하기]
[다른 문제]
[메인으로]
```

## 구현 결정

기획서에서 정하지 않은 부분은 다음과 같이 정했다(2026-10-17). 코드: `scripts/Games/Quiz/`, 규칙·출제·점수: `scripts/Core/QuizRules.cs`.

- **흐름**: 문제 고르기 → 10문제 → "다 풀었어요!"(10문제 모두 한 번에 맞히면 "모두 맞혔어요!"와 색종이) → 공통 결과 화면(다시 하기 / 다른 문제 / 메인으로). 플레이 중 "그만하기"는 다른 게임처럼 "정말 그만할까요?"를 한 번 묻는다.
  - **카운트다운 없음**: 시간 제한 게임이 아니라서 3·2·1을 빼고 "시작!" 소리 뒤 바로 첫 문제가 나온다. 화면에 시계도 없다.
- **문제 고르기 화면**: 문제(색깔 / 숫자 / 섞어서) → 난이도(쉬움 / 보통 / 어려움) → 배경 → 응원 친구. `settings.cfg`의 `[quiz]` 섹션에 저장한다. 기본값은 색깔, 보통, 하늘. 오른쪽에 고른 종류와 난이도로 만든 예시 카드(2 / 4 / 6장)가 바로 나온다.
  - **섞어서**: 문제마다 색깔과 숫자 중 하나를 무작위로 고르되 같은 종류가 세 번 연달아 나오지 않는다.
  - 같은 그림 찾기, 개수 찾기는 초기 버전 범위 밖이라 만들지 않았다(개수 찾기는 과일 그림으로 확장 가능, 개선 Q-6).
- **난이도**: 쉬움 2장 / 보통 4장 / 어려움 6장. 숫자는 쉬움·보통 1~5, 어려움 1~9(6장을 서로 다르게 고르려면 5개로는 모자람).
  - 카드 배치: 2장·4장은 한 줄, 6장은 3x2. 화면 높이에 맞춰 가능한 크게(쉬움 카드가 가장 큼).
- **숫자 6~9 카드**: 그림이 1~5뿐이라 6~9는 코드로 그린다(`QuizCard.DrawNumberCard`: 어두운 테두리, 색 테두리, 연한 바탕, 굵은 외곽선 숫자. 글꼴은 `UiTheme.Font`). 진짜 그림이 생기면 `num_6.png`~`num_9.png`를 넣고 `PaintedNumbers`를 9로 바꾸면 된다(`docs/resources.md`).
- **문제 문장과 예시 그림**: 글을 못 읽는 아이를 위해 문장 왼쪽에 큰 예시를 둔다. 색깔은 그 색의 동그란 물감 방울, 숫자는 큰 검은 숫자(정답 카드와 같은 그림을 보여 주면 그림 맞추기가 되므로 일부러 다르게). 문제가 나올 때 "띵동" 소리, 문장 판이 튀어나오고 예시가 한 번 튄다. 카드는 하나씩 놓이듯 등장한다.
  - 문장: "빨간색을 찾아주세요!", "숫자 3을 찾아주세요!"(을/를은 숫자를 읽는 소리에 맞춤: 삼을, 사를). 도형마다 색이 하나뿐이라 "공" 대신 "색"으로 묻는다.
- **출제**(`QuizDeck`): 정답은 종류별로 섞은 주머니에서 꺼내 모든 값이 한 번씩 나온 뒤에 반복되고, 같은 정답이 연달아 나오지 않는다. 오답 카드는 나머지 값에서 무작위. 정답 자리가 세 번 연속 같은 칸이 되지 않는다(쉬움 2장에서 번갈아 나오는 규칙이 생기지 않도록 두 번 연속까지는 허용).
- **오답**: 고른 카드가 흔들리고 흐려지며 다시 누를 수 없게 된다. 문장 아래에 "한 번 더 찾아볼까요?"(분홍), 예시 그림이 한 번 튀어 다시 보게 하고, 낮고 부드러운 "음?" 소리. 정답 카드는 절대 표시하지 않는다. 빨간 X(`ui/cross.png`)와 감점은 쓰지 않는다.
- **정답**(핵심 순간): "딩동댕" 종소리(도·미·솔·높은 도), 문장 아래에 초록 "딩동댕!", 카드가 커지고 체크 표시(`ui/check.png`)가 붙고 카드 색 불꽃과 별이 튄다. 나머지 카드는 사라진다. 응원 친구가 깡충 뛴다.
  - **한 번에 맞히면** 별이 카드에서 위쪽 진행 줄의 자기 칸으로 날아가 박히고(맞힌 개수만큼 음이 올라가는 "똑"), 세 문제 연속이면 친구가 응원한다.
  - **다시 골라서 맞히면** 별 대신 파란 동그라미로 칸을 채우고 친구가 "찾았다!"라고 한다(칭찬은 같고 별만 없음).
  - 약 1.1초 뒤 다음 문제. 10번째 정답은 불꽃과 별이 더 크고 반짝 소리가 더해진다(클라이맥스).
- **진행 표시**: 위쪽 가운데 10칸. 지금 문제 칸은 주황색으로 두근거리고, 끝난 칸은 별(한 번에 정답) 또는 파란 동그라미(다시 골라 정답).
- **점수와 랭킹**: 점수 = 처음 고른 카드가 정답인 문제 수(= 별 개수). 시간 = 카드를 누를 수 있는 동안만 더한 시간(등장·정답 연출 시간은 빼서 연출 길이와 상관없이 공평하게). 랭킹은 맞힌 개수 많은 순, 같으면 시간 짧은 순. 0개면 기록하지 않는다.
  - **난이도별 랭킹**: 2장 중 고르기와 6장 중 고르기는 비교할 수 없으므로 쉬움/보통/어려움이 각자 Top 10을 가진다(`records.json` 키 `quiz:easy`, `quiz:normal`, `quiz:hard`). 문제 종류(색깔/숫자/섞어서)는 나누지 않는다. 난이도 차이보다 작고, 나누면 9개 표가 되어 기록이 흩어진다.
  - 결과 화면: "다 풀었어요!" / "10문제 중" / "N문제를 맞혔어요!" / 별 10개 중 N개가 숫자 count-up과 함께 켜지고 "별 N개". 오른쪽 순위표 제목은 "숫자 / 색깔 퀴즈 · 보통 순위".
  - 메인 메뉴 카드: 기록이 있는 가장 어려운 난이도의 최고 기록("보통 최고 9문제 · 6.8초"). 기록 화면: 퀴즈 탭에 쉬움/보통/어려움 탭(처음엔 메뉴 카드와 같은 난이도).
- **개발용**: `-- --game=quiz --autoplay`는 잠깐 본 뒤 카드를 누른다. 두 번째 문제는 항상, 그 뒤로는 25% 확률로 먼저 틀린 카드를 골라 다시 고르기 흐름도 확인한다.
