# 아기새 날기

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 추가 추천 12절(Flappy 스타일). 게임 방식만 가져오고 아이용으로 바꿨다.

## 게임 목표

화면을 누를 때마다 아기새가 파닥 날아오른다. 나무 기둥 사이의 틈을 지나갈 때마다 1점. 최대한 많이 지나간다.

## 게임 플로우

`꾸미기(난이도 → 배경 → 속도) → 3·2·1 카운트다운(아기새가 제자리에서 둥실) → 첫 누름부터 출발 → 기둥 통과 → 부딪힘 → "앗! 다시 해볼까요?" → 결과 화면`

- 공룡 점프와 같은 흐름이다. 부딪히면 판이 끝나지만 부드럽게 끝낸다(아래 "부딪힘").
- 첫 누름 전까지 아기새는 공중에 떠서 기다리고 "화면을 누르면 날아요!"가 깜박인다.

## 조작

- 한 버튼: SPACE(↑, W도 됨), 마우스 클릭, 화면 어디든 터치. 터치 이벤트만 처리한다.
- 누르면 위로 정해진 속도로 튀어 오르고, 놓아 두면 천천히 떨어진다.

## 화면 구조

```text
   ┃┃            ┃┃
   ┃┃            ┃┃
                     점수 7
 🐤       ┃┃
   ┃┃     ┃┃     ┃┃
___________________________
```

- 가로로 흐르는 게임이라 화면 전체를 쓴다. 아기새는 왼쪽 30% 위치에 고정, 기둥과 배경이 오른쪽에서 왼쪽으로 흐른다.
- 위: 그만하기, 가운데 점수. 땅은 아래 10%.

## 규칙과 판정

- 중력과 날갯짓 속도는 고정(화면 높이 단위). 원본보다 중력을 약하게, 최고 낙하 속도를 낮게 해서 아이가 박자를 맞추기 쉽게 한다.
- **천장과 땅은 끝나지 않는다**: 위 끝에서는 머리를 콩 하고 멈추고, 땅에서는 통통 튀며 걷는다(다시 누르면 날아오름). 원본은 땅에 닿으면 끝이지만 아이가 너무 쉽게 끝나서 바꿨다.
- **부딪힘**(기둥에 닿았을 때만): 아기새가 어지러운 얼굴(`bird_bump`)로 빙글 돌며 땅에 살포시 내려앉고 머리 위로 별이 돈다. 만화 같은 "뿅" 소리, 약한 흔들림, 붉은색·경고음 없음. 0.45초 뒤 "앗! 다시 해볼까요?", 2초 뒤 결과 화면(첫 버튼 "다시 하기").
- **넉넉한 판정**: 충돌 원은 그림보다 훨씬 작게(그림 폭의 55%), 기둥은 나뭇잎 장식을 빼고 줄기만. 닿은 뒤 0.08초 유예(공룡 점프와 같은 방식).
- **처음 3개 기둥**은 틈이 1.3배 넓고 높이 차이가 작다(몸풀기).

## 난이도

틈 크기로 나눈다. 점수를 비교할 수 없으므로 **난이도별 랭킹**(`flappy:easy`, `flappy:normal`, `flappy:hard`).

| 변형 | 틈 높이(화면 높이) | 다음 틈과 높이 차 최대 |
|---|---|---|
| 쉬움 | 0.42 | 0.20 |
| 보통 | 0.36 | 0.28 |
| 어려움 | 0.31 | 0.35 |

- 흐르는 속도는 10개마다 조금씩 빨라지고 30개에서 멈춘다("빨라져요!" 문구). 꾸미기 속도(느림 / 보통 / 빠름)를 곱한다(랭킹은 나누지 않음, 다른 게임과 같다).
- 기둥 간격은 가장 빠른 속도에서도 다음 틈 높이까지 날아갈 시간이 남게 Core에서 계산하고 테스트로 확인한다(공룡 점프의 `MinGap`과 같은 방식).

## 점수와 랭킹

- 기둥 한 쌍을 지날 때마다 +1. 랭킹: 점수 높은 순(`RankOrder.ScoreDesc`), "N개". 0개면 기록하지 않는다. 보조 줄: "N초 동안 날았어요".
- 결과 화면 버튼: 다시 하기 / 꾸미기 / 메인으로.

## 연출 강도

- 날갯짓(가장 자주): 날개 3프레임이 빨리 돌고 몸이 살짝 늘어남, 작은 "파닥". 오를 때 고개를 들고 떨어질 때 숙인다.
- 통과: 한 음씩 올라가는 "띵", 틈 사이 작은 별과 "+1", 기둥 잎이 살랑.
- 10개마다: 반짝 소리, 별 소나기, "10개! 최고야!", 약한 흔들림.

## 원본에서 바꾼 점

- **땅·천장 충돌 없음**: 너무 쉽게 끝나는 원인이라 기둥만 판정한다.
- **부딪힘을 실패가 아닌 "어지러움"으로**: 떨어지는 연출 대신 살포시 내려앉기, 공룡 점프와 같은 문구로 다시 하기를 권한다.
- **몸풀기 기둥, 넉넉한 판정, 약한 중력**: 아이의 반응 속도에 맞췄다.

## 사용 리소스

- `flappy/bird_01.png` ~ `bird_03.png`(날갯짓), `flappy/bird_bump.png`, `flappy/pillar_body.png`(세로로 늘림), `flappy/pillar_cap.png`, `menu/flappy.png`. 배경은 공용 `Scenery`(기본 하늘, 구름은 `CloudDrift` 음수로 왼쪽으로 흐름), 땅은 `dino/ground_tile.png`(없으면 지금의 `dino/ground.png`).
- **리소스가 없을 때**: 아기새는 노란 원 몸 + 주황 부리 + 날개 타원을 코드로 그려 날개만 위아래로 흔든다. 기둥은 갈색 둥근 사각형 + 초록 잎 뭉치(원 여러 개).

## 구현 메모

- `scripts/Core/FlappyRules.cs`: 중력·날갯짓 속도, 틈 표(변형별), 기둥 간격·높이 생성(난수 주입), 충돌 상자, 속도 단계. 단위 테스트 `FlappyRulesTests`(모든 속도·높이 차 조합에서 도달 가능).
- `scripts/Games/Flappy/`: 씬 `scenes/games/flappy.tscn`. 오브젝트는 `World` 아래(흔들림 대상).
- 공통: `GameCatalog`에 `flappy`(변형 `FlappyRules.Variants`), `Countdown`, `ResultPanel`, `QuitConfirm`. 설정 `[flappy]`(`level`, `scenery`, `speed`). 응원 친구는 공룡 점프처럼 넣지 않는다(흐르는 화면과 겹침).
- 개발용 `--autoplay`: 다음 틈 가운데보다 낮아지면 누른다. 20~35점 중 무작위 점수에서 누르지 않아 부딪히고 결과 화면까지 간다.

## 완료 조건

- 한 버튼으로 날아오르고 중력으로 떨어진다. 땅·천장에서 끝나지 않는다.
- 기둥 통과 +1, 기둥에 부딪히면 부드러운 끝 연출 → 결과 화면.
- 난이도별 Top 10 기록.
- 기둥 간격 도달 가능성 단위 테스트 통과, `--game=flappy --autoplay` 스모크 테스트 오류 없음.

### 기획과 달라진 점

- **기둥 간격 규칙**: 기본 간격 0.85에, 두 틈의 높이 차로 계산한 최소 간격(줄기 폭 + 충돌 원 + 속도 × (반응 0.4초 + 이동 시간))보다 좁아지지 않게 했다. 이동 시간은 "틈 안 어디에 있든" 다음 틈 안쪽까지의 최악 거리를, 올라갈 때는 꼭대기마다 한 번 누르는 속도(초당 약 0.4)로, 내려갈 때는 막 날갯짓한 직후라고 보고(한 번 솟았다 떨어지는 시간까지) 계산한다. 테스트에서 처음엔 "정지 상태에서 낙하"로만 계산했더니 반응 직전에 누른 경우 가장 빠른 속도에서 부딪혀서 고쳤다. 다음 기둥 간격은 두 기둥 뒤 속도 단계 기준으로 미리 잡는다(`PlanningSpeed`).
- **공정성 테스트**: 규칙 계산 외에, 꼭대기마다 한 번만 누르고 기둥을 지난 뒤 0.4초는 예전 높이를 지키는 "조심스러운 아이" 봇이 모든 난이도 × 모든 속도에서 기둥 80개를 한 번도 안 부딪히고 지나가는지 시뮬레이션으로 확인한다.
- **틈 높이**: 다음 틈은 이전 틈 ± 최대 높이 차 안에서 무작위, 화면 위·아래 끝에 줄기가 0.08 이상 남는 범위 밖으로 나가면 반대쪽으로 튕겨 넣는다. 첫 틈은 아기새가 기다리는 높이(0.45)에 둔다. 몸풀기 3개는 틈 1.3배, 높이 차 0.4배.
- **카운트다운 중 누름**: 날개만 파닥이고 소리만 난다(판은 카운트다운 뒤 첫 누름부터). 기둥도 첫 누름 뒤에 오른쪽 끝에서 나온다. 땅과 구름은 처음부터 흐른다.
- **부딪힘**: `bird_bump` 그림에 별과 고리가 이미 그려져 있어 도는 별을 따로 더하지 않았다. 대신 뒤로 살짝 튀며 한 바퀴 돌고 풀밭에 살포시 내려앉아 좌우로 갸우뚱한다. 소리는 공룡과 같은 `Tumble`("뿌우웅"), 부딪힌 기둥은 좌우로 살짝 흔들린다.
- **효과음**(기존 합성음만): 날갯짓 = `CardFlip`(가벼운 "파닥"), 천장 = `WallBump`("콩"), 땅 = `Step`("톡", 번갈아 음 높이), 통과 = `PassTick`(10개 안에서 한 음씩 올라감), 10개마다 = `Cheer`, 속도 단계 = `Whoosh` + 배너 + 바람 줄.
- **기둥 그림**: `pillar_body`를 세로로 늘리지 않고 몸통 띠를 거울 반복으로 이어 붙이고 풀 뿌리는 땅(위 기둥은 화면 위 끝)에 한 번 그린다. 뚜껑(`pillar_cap`)은 35%만 틈 안으로 나온다(판정은 줄기 끝까지만이라 틈이 보이는 것보다 넉넉하다). 위 기둥은 아래 기둥을 위아래로 뒤집은 것.
- **땅**: `dino/ground_tile.png`의 양 끝 투명 열 때문에 그대로 반복하면 이음선이 보여서, 양 끝 3px를 잘라 한 장씩 번갈아 뒤집어 그린다.
- **점수판**: 위 가운데에 아기새 아이콘 + "N개", 왼쪽 위 그만하기, 오른쪽 위 지금 난이도의 최고 기록. 결과 화면 제목은 "잘 날았어요!", 0개면 "다음엔 나무 사이로 꼭 지나가 보자!"(기록 안 함).
- 응원 친구는 기획대로 넣지 않았다.

### 자동 플레이

- 꾸미기 0.6초에 시범 날갯짓, 1.4초에 시작 → 카운트다운 뒤 1.2초 기다렸다가("화면을 누르면 날아요!"가 보이게) 첫 누름.
- 다음 기둥 틈 가운데보다 0.03 아래로 내려가면 누른다(0.18초에 한 번까지). 판단은 물리 작은 단계(1/120초)마다 해서 `--fixed-fps 5` 화면 저장에서도 같은 동작.
- 20~35개 중 무작위 점수에 이르면 더 누르지 않아 땅을 통통 걸으며 다음 기둥에 부딪히고 결과 화면까지 간다.
- 헤드리스 스모크 테스트에서는 애벌레처럼 `Engine.TimeScale = 2`(`--autoplay` + 헤드리스일 때만, 씬을 나가면 1로).
