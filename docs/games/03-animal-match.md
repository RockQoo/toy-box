# 동물 짝 맞추기

## 게임 목표

뒤집혀 있는 카드 중 같은 동물 두 장을 찾아 모든 카드의 짝을 맞춘다.

## 게임 플로우

`메인 화면 → 난이도 선택 → 카드 랜덤 배치 → 전체 카드 잠깐 공개 → 카드 뒤집기 → 플레이 → 모든 짝 완성 → 결과 화면`

## 기본 화면

초급 예시:

```text
?   ?   ?

?   ?   ?
```

총 6장의 카드가 배치된다.

## 카드 선택 규칙

첫 번째 카드를 선택하면 카드가 뒤집힌다.

두 번째 카드를 선택하면 두 카드를 비교한다.

같은 동물이면:

- 성공 효과음
- 카드가 열린 상태로 유지
- 맞춘 쌍 카운트 +1

다른 동물이면:

- 약 1초 동안 두 카드를 보여줌
- 다시 뒷면으로 뒤집음

카드 비교 중에는 추가 카드를 누를 수 없도록 입력을 잠근다.

## 난이도

### 쉬움
- 카드 6장
- 3쌍

### 보통
- 카드 8장
- 4쌍

### 어려움
- 카드 12장
- 6쌍

## 동물 예시

- 강아지
- 고양이
- 토끼
- 판다
- 사자
- 개구리

## 아이 친화 기능

게임 시작 시 약 2초 동안 모든 카드를 공개한다.

```text
강아지  고양이  토끼
토끼    강아지  고양이
```

그 후 모든 카드를 뒤집는다.

실패 횟수에 따른 감점은 없다.

## 결과 화면

```text
모든 동물을 찾았어요!

걸린 시간
42초

뒤집은 횟수
18번

[다시 하기]
[다음 난이도]
[메인으로]
```
