# 동물 짝 맞추기

## 게임 목표

뒤집혀 있는 카드 중 같은 동물 두 장을 찾아 모든 카드의 짝을 맞춘다.

## 게임 플로우

`메인 화면 → 난이도 선택 → 카드 랜덤 배치 → 전체 카드 잠깐 공개 → 카드 뒤집기 → 플레이 → 모든 짝 완성 → 결과 화면`

## 기본 화면

초급 예시:

```text
?   ?   ?

?   ?   ?
```

총 6장의 카드가 배치된다.

## 카드 선택 규칙

첫 번째 카드를 선택하면 카드가 뒤집힌다.

두 번째 카드를 선택하면 두 카드를 비교한다.

같은 동물이면:

- 성공 효과음
- 카드가 열린 상태로 유지
- 맞춘 쌍 카운트 +1

다른 동물이면:

- 약 1초 동안 두 카드를 보여줌
- 다시 뒷면으로 뒤집음

카드 비교 중에는 추가 카드를 누를 수 없도록 입력을 잠근다.

## 난이도

### 쉬움
- 카드 6장
- 3쌍

### 보통
- 카드 8장
- 4쌍

### 어려움
- 카드 12장
- 6쌍

## 동물 예시

- 강아지
- 고양이
- 토끼
- 판다
- 사자
- 개구리

## 아이 친화 기능

게임 시작 시 약 2초 동안 모든 카드를 공개한다.

```text
강아지  고양이  토끼
토끼    강아지  고양이
```

그 후 모든 카드를 뒤집는다.

실패 횟수에 따른 감점은 없다.

## 결과 화면

```text
모든 동물을 찾았어요!

걸린 시간
42초

뒤집은 횟수
18번

[다시 하기]
[다음 난이도]
[메인으로]
```

## 구현 결정

기획서에서 정하지 않은 부분은 다음과 같이 정했다(2026-10-17). 코드: `scripts/Games/Memory/`, 규칙·배치·판정: `scripts/Core/MemoryRules.cs`(`MemoryRules`, `MemoryBoard`).

- **흐름**: 난이도 고르기 → 카드가 아래쪽 더미에서 한 장씩 날아와 뒷면으로 놓임 → 왼쪽 위부터 물결처럼 모두 앞면으로 뒤집혀 약 2초 공개("잘 기억해요!", 친구 "잘 봐 둬!") → 다시 모두 뒷면 → "시작!" 소리와 함께 시계 시작 → 모든 짝 완성 → "모두 찾았어요!" → 공통 결과 화면. 플레이 중 "그만하기"는 다른 게임처럼 "정말 그만할까요?"를 묻는다(열려 있는 동안 시계도 멈춤).
  - **카운트다운 없음**: 퀴즈처럼 시간 제한 게임이 아니고, 카드 공개가 준비 시간 역할을 한다.
- **난이도 고르기 화면**: 난이도(쉬움 / 보통 / 어려움) → 배경 → 응원 친구. `settings.cfg`의 `[memory]` 섹션에 저장한다. 기본값은 쉬움, 공원, 판다. 오른쪽에 그 난이도의 카드 배치(앞면)와 "카드 6장 · 3쌍"이 바로 나온다.
- **난이도와 배치**: 쉬움 6장(3x2) / 보통 8장(4x2) / 어려움 12장(4x3). 동물 8종 중 쌍 수만큼 무작위로 골라 두 장씩 섞는다. 카드는 위쪽 막대 아래 영역에 가능한 크게 놓고, 오른쪽 아래 응원 친구 자리를 피하도록 양옆 여백을 둔다(1280x720에서 카드 높이: 쉬움·보통 약 290 / 250, 어려움 약 190). 어려움은 6x2보다 4x3이 카드 크기가 같으면서 한눈에 들어와서 4x3으로 했다.
- **카드 그림**: `assets/sprites/animal/`의 카드 그림(테두리 포함)을 그대로 쓰고, 뒷면(`card_back.png`)은 비율이 조금 달라 동물 카드와 같은 비율로 맞춰 그린다.
- **뒤집기 연출**(`MemoryCard.Turn`): 살짝 들리면서 가로 폭이 0으로 줄고 → 그림이 바뀌고 → 튕기듯 펴진 뒤 착지할 때 살짝 찌그러진다. 들리는 동안 그림자가 작고 옅어진다. 위치·크기를 바꾸지 않고 그리기만 바꿔서 배치나 누름 효과와 부딪히지 않는다.
- **규칙**: 첫 카드를 누르면 뒤집힌다. 두 번째 카드를 누르면 비교한다. 이미 열린 카드나 맞춘 카드를 누르면 아무 일도 없다(뒤집기 횟수도 그대로).
  - **짝 성공**(중요한 순간): 밝은 종소리 "띵동"(찾은 쌍 수만큼 음이 올라감), 두 카드가 차례로 깡충 뛰고 금색 테두리가 생겨 반짝이며, 별이 튀고, 동물 이름("사자!")이 떠오른다(글을 못 읽어도 소리·연출과 함께 이름을 보게). 위쪽 가운데 쌍 칸이 그 동물 그림으로 채워진다. 실수 없이 두 쌍 넘게 이어 찾으면 가끔 친구가 응원한다("척척!", "기억력 최고!").
  - **짝 실패**: 두 카드를 약 1초 보여 준 뒤 조용히 다시 뒷면으로 뒤집는다. 실패 소리, 흔들림, 감점 없음. 보여 주는 동안 다른 카드는 누를 수 없다.
  - **마지막 짝**(클라이맥스): 별이 더 크게 튀고 카드가 두 번 뛴다. 이름이 사라질 즈음 모든 카드가 물결처럼 뛰고, 팡파르와 색종이, "모두 찾았어요!", 친구 "모두 찾았다!". 약 2초 뒤 결과 화면.
- **위쪽 막대**: 왼쪽 "그만하기", 가운데 찾은 쌍 칸(쌍 수만큼, 플레이 시작 때 나타남. 공개 중에는 그 자리에 "잘 기억해요!"), 오른쪽 작게 "12초 · 뒤집기 6번". 시계는 아이를 재촉하지 않게 작고 옅게 둔다.
- **시간과 뒤집은 횟수**: 시간은 "시작!"부터 마지막 짝까지(짝 실패 뒤 보여 주는 1초 포함, 그만하기 창이 열린 동안은 제외). 뒤집은 횟수는 앞면으로 뒤집은 카드 수(한 번 시도 = 2번). 실패에 대한 다른 불이익은 없다.
- **랭킹**: 걸린 시간 짧은 순, 같으면 뒤집은 횟수 적은 순(`RankOrder.TimeAscScoreAsc`, 기록의 `Score`에 뒤집은 횟수를 저장). 모든 판은 끝까지 하면 기록 대상이다.
  - **난이도별 랭킹**: 쉬움/보통/어려움이 각자 Top 10을 가진다(`records.json` 키 `memory:easy`, `memory:normal`, `memory:hard`). 배경·친구로는 나누지 않는다.
  - 순위표와 메인 메뉴 카드 표시: "23.4초 · 18번"(메뉴 카드: "어려움 최고 23.4초 · 18번").
- **결과 화면**: "모든 동물을 찾았어요!" / "걸린 시간" / "N.N초"(count-up) / count-up이 끝나면 "뒤집은 횟수 N번"(공통 `ResultSpec.Detail`). 버튼: 다시 하기 / 다음 난이도(어려움에서는 "난이도 고르기"로 바뀌어 고르기 화면으로) / 메인으로.
- **개발용**: `-- --game=memory --autoplay`는 기억력이 적당한 아이처럼 플레이한다. 공개 때 카드의 35%, 뒤집은 카드의 70%만 기억하고, 기억한 짝이 있으면 그것을, 없으면 새 카드를 뒤집은 뒤 기억한 짝이나 아무 카드를 고른다. 그래서 짝 실패도 나온다. 난이도는 `settings.cfg`의 `[memory] level`(0~2)을 따른다.
