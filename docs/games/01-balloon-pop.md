# 풍선 터뜨리기

## 게임 목표

30초 동안 화면 아래에서 위로 올라오는 풍선을 최대한 많이 터뜨리는 게임.

## 게임 플로우

`메인 화면 → 풍선 색 선택 → 배경 선택 → 캐릭터 선택 → 시작 버튼 → 3초 카운트다운 → 게임 시작 → 30초 플레이 → 결과 화면`

## 플레이 규칙

- 화면 아래쪽의 랜덤한 X 위치에서 풍선이 생성된다.
- 풍선은 위쪽으로 일정 속도로 이동한다.
- 플레이어가 풍선을 클릭하거나 터치하면 풍선이 터진다.
- 풍선을 터뜨리면 점수 +1.
- 터지는 순간 “펑!” 효과음을 재생한다.
- 작은 별이나 파티클 효과를 추가할 수 있다.
- 풍선을 놓쳐서 화면 위로 사라져도 감점은 없다.

## 게임 시간

기본 플레이 시간은 **30초**.

상단 UI 예시:

```text
점수 12                         남은 시간 18초
```

시간이 0초가 되면:

- 새로운 풍선 생성 중지
- 화면에 남아 있는 풍선 제거
- 결과 화면으로 이동

## 난이도 변화

| 시간 | 풍선 이동 속도 | 생성 간격 |
|---|---:|---:|
| 0~10초 | 느림 | 1.0초 |
| 10~20초 | 보통 | 0.7초 |
| 20~25초 | 빠름 | 0.5초 |
| 25~30초 | 매우 빠름 | 0.35초 |

아이용 게임이므로 실패감을 주기보다 시간이 갈수록 화면이 신나고 활발해지는 느낌을 목표로 한다.

## 커스터마이징

게임 시작 전 아이가 선택할 수 있는 항목:

- 풍선 색상: 빨강 / 노랑 / 파랑 / 초록 / 랜덤
- 배경: 하늘 / 공원 / 우주 / 바다
- 캐릭터: 토끼 / 고양이 / 공룡 등
- 시작 속도: 느림 / 보통 / 빠름

캐릭터는 화면 한쪽에서 응원하는 역할로 사용해도 된다.

## 특수 풍선

초기 버전에서는 없어도 되며, 이후 확장 기능으로 추가한다.

- 별 풍선: +3점
- 무지개 풍선: 주변 풍선도 같이 터짐
- 폭탄 풍선: 어린이용 초기 버전에서는 제외 권장

## 결과 화면

```text

```

```text
최고 기록!
```

축하 애니메이션을 표시한다.
