# 미로 탈출

## 게임 목표

캐릭터를 움직여 미로의 출구까지 도착한다.

## 게임 플로우

`캐릭터 선택 → 미로 난이도 선택 → 게임 시작 → 캐릭터 이동 → 출구 도착 → 성공 애니메이션 → 결과 / 다음 미로`

## 조작

PC:

```text
↑
← ↓ →
```

모바일에서는 화면 하단에 큰 방향 버튼을 표시한다.

```text
       ▲

   ◀   ▼   ▶
```

## 기본 구조

```text
#########
#P      #
# ### # #
#   # # #
### #   #
#      E#
#########
```

- P = 플레이어
- E = 출구
- # = 벽

## 이동 규칙

- 방향키 또는 버튼을 누르면 한 칸씩 이동
- 벽이 있는 방향으로는 이동할 수 없음
- 벽에 부딪히면 작은 “통!” 효과음 재생 가능
- 출구에 도착하면 성공 처리

## 난이도

### 쉬움
- 5 x 5
- 길이 단순함
- 막다른 길 거의 없음

### 보통
- 7 x 7
- 갈림길 증가

### 어려움
- 10 x 10
- 막다른 길 증가

초기 버전에서는 미로를 미리 제작해서 사용하고, 랜덤 미로 생성은 이후 확장 기능으로 두는 것이 좋다.

## 추가 목표

미로 안에 별을 배치할 수 있다.

```text
별 3/3
```

출구에 도착하는 것 외에 별을 모으는 재미를 추가한다.

## 성공 화면

```text
탈출 성공!

별 3/3

걸린 시간
25초

[다음 미로]
[다시 하기]
[메인으로]
```
