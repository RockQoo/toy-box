# 미로 탈출

## 게임 목표

캐릭터를 움직여 미로의 출구까지 도착한다.

## 게임 플로우

`캐릭터 선택 → 미로 난이도 선택 → 게임 시작 → 캐릭터 이동 → 출구 도착 → 성공 애니메이션 → 결과 / 다음 미로`

## 조작

PC:

```text
↑
← ↓ →
```

모바일에서는 화면 하단에 큰 방향 버튼을 표시한다.

```text
       ▲

   ◀   ▼   ▶
```

## 기본 구조

```text
#########
#P      #
# ### # #
#   # # #
### #   #
#      E#
#########
```

- P = 플레이어
- E = 출구
- # = 벽

## 이동 규칙

- 방향키 또는 버튼을 누르면 한 칸씩 이동
- 벽이 있는 방향으로는 이동할 수 없음
- 벽에 부딪히면 작은 “통!” 효과음 재생 가능
- 출구에 도착하면 성공 처리

## 난이도

### 쉬움
- 5 x 5
- 길이 단순함
- 막다른 길 거의 없음

### 보통
- 7 x 7
- 갈림길 증가

### 어려움
- 10 x 10
- 막다른 길 증가

초기 버전에서는 미로를 미리 제작해서 사용하고, 랜덤 미로 생성은 이후 확장 기능으로 두는 것이 좋다.

## 추가 목표

미로 안에 별을 배치할 수 있다.

```text
별 3/3
```

출구에 도착하는 것 외에 별을 모으는 재미를 추가한다.

## 성공 화면

```text
탈출 성공!

별 3/3

걸린 시간
25초

[다음 미로]
[다시 하기]
[메인으로]
```

## 구현에 필요한 주요 오브젝트

- MazeManager
- TileMap / Grid
- Player
- Exit
- Star
- Direction UI
- Result UI
- AudioManager


## 구현 결정

기획서에서 정하지 않은 부분은 다음과 같이 정했다(2026-10-17). 코드: `scripts/Games/Maze/`, 미로 생성·판정: `scripts/Core/MazeRules.cs`(`MazeRules`, `Maze`, `MazeGenerator`, `MazeRun`).

- **흐름**: 꾸미기(난이도 → 캐릭터 → 배경) → 미로가 미끄러져 나타나고 별 3개가 차례로 톡 튀어나온 뒤 캐릭터가 출발 칸에 떨어진다 → "출구까지 가요!" → 이동 → 출구 도착 → "탈출 성공!" → 공통 결과 화면. 카운트다운은 없다(시간 제한 게임이 아니고, 시계는 첫 이동부터 간다). 플레이 중 "그만하기"는 다른 게임처럼 "정말 그만할까요?"를 묻는다.
- **꾸미기 화면**: 난이도(쉬움 / 보통 / 어려움) → 캐릭터(응원 친구와 같은 5종: 토끼·판다·펭귄·사자·공룡, 미로 안에서 직접 움직이는 캐릭터) → 배경. `settings.cfg`의 `[maze]` 섹션(`level`, `character`, `scenery`)에 저장한다. 기본값은 쉬움, 토끼, 공원. 오른쪽에 "시작!"을 누르면 할 미로가 캐릭터·별과 함께 작게 나온다("5 x 5 · 1번 미로").
- **미리 만든 미로**(기획서: 초기 버전은 미리 제작): 난이도마다 5개. 직접 그린 표 대신 `MazeGenerator`(자체 난수라 어디서나 같은 결과)로 정해 둔 시드에서 만든다(`MazeRules.Seeds`). 시드는 아래 조건을 만족하는 것 중에서 골랐고, 단위 테스트(`MazeRulesTests`)가 모든 미로에 대해 확인한다. 첫 미로 모양은 테스트에 그림으로 고정해 생성기가 몰래 바뀌지 않게 했다.
  - 쉬움 5x5: 깊이 우선으로 긴 길을 판 뒤 막다른 길의 70%를 이웃과 이어 고리로 만든다. 막다른 길 0~2개, 최단 경로 10걸음 이상.
  - 보통 7x7: 가끔 갈래를 치고, 막다른 길의 절반쯤 남긴다. 막다른 길 3~8개, 16걸음 이상.
  - 어려움 10x10: 갈래가 더 많고 막다른 길을 모두 남긴다. 막다른 길 10~30개(고른 미로는 14~20개), 26걸음 이상.
  - 출발은 왼쪽 위, 출구는 오른쪽 아래로 고정했다(아이가 어디로 가야 하는지 바로 안다). 모든 칸에 갈 수 있다.
- **다음 미로**: 탈출하면 그 난이도의 다음 미로 번호를 `[maze] next_easy|next_normal|next_hard`에 저장한다. 결과 화면 "다음 미로"와 꾸미기 화면 "시작!"은 다음 미로를, "다시 하기"는 방금 한 미로를 한다. 5번 다음은 1번으로 돌아간다. 무작위 생성은 확장 기능으로 남겼다(생성기는 이미 있으므로 시드만 바꾸면 된다).
- **별**: 미로마다 3개. 최단 경로(여러 개면 그중 어느 것)에도 없는 칸에만 놓아서 별을 모으려면 옆길로 잠깐 들러야 한다. 출구를 지나야만 갈 수 있는 칸에는 놓지 않는다. 최단 경로를 3등분해 앞·가운데·뒤쪽에 하나씩 매달리게 하고, 막다른 길을 우선한다. 쉬움은 길에서 2걸음, 보통은 4걸음 안쪽에만 둔다. 지나가면 줍는다.
- **조작**: 입력 한 번에 한 칸. 방향키와 WASD(물리 키라 한글 입력 상태에서도 됨), 오른쪽 아래 큰 방향 버튼(기획서 배치 ▲ / ◀ ▼ ▶, 버튼 118px), 미로 위 스와이프(손가락을 끌면 셀 크기의 60%마다 한 칸, 계속 끌면 계속 간다). 키나 버튼을 누르고 있으면 0.3초 뒤부터 0.19초마다 한 칸씩 계속 간다. 이동 중 누른 입력은 하나 기억했다가 이동이 끝나면 바로 처리한다. 키보드로 움직이면 화면의 같은 방향 버튼이 살짝 눌려 보인다.
- **벽에 부딪힘**: 작은 "통"(코드 합성 `WallBump`), 캐릭터가 벽 쪽으로 살짝 밀렸다 돌아오며 찌그러지고 초록 잎 몇 개가 튄다. 감점·시간 추가 없음.
- **연출 강도**(`/polish-review` 3절): 한 칸 이동은 가볍게(0.14초 미끄러지며 작게 뛰고 착지 때 찌그러짐, 발소리 같은 작은 "톡" 두 음 번갈아, 지나온 칸에 옅은 발자국). 별 줍기는 중요하게(별 터짐과 반짝이, 올라가는 종소리 `StarPickup`, 캐릭터 깡충, "반짝!" 글자, 별이 오른쪽 위 별 칸으로 날아가 켜짐. 세 번째 별은 "별을 다 모았어요!"와 환호, 출구 깃발이 뛰어 다음 목표를 알림). 탈출은 클라이맥스(깃발 점프, 캐릭터가 커지며 두 번 뛰고 두 번째에 한 바퀴, 팡파르, 별과 고리 터짐, 색종이, "탈출 성공!", 약 2.3초 뒤 결과 화면).
- **그림**: 타일 그림이 없어서 코드로 그린다(`MazeBoard`, `MazeExit`). 크림색 바닥에 옅은 체크무늬, 남색 테두리가 있는 둥글고 두꺼운 초록 울타리 벽(윗면 밝은 줄), 출발 칸 하늘색 매트, 출구는 빛나는 금색 매트와 흔들리는 분홍 깃발. 별은 `ui/star.png`가 둥실 흔들리고 노란 빛이 깜박인다.
- **화면 배치**: 미로는 왼쪽에 가능한 크게, 오른쪽 열에 위부터 "어려움 · 1번 미로"·그만하기, 별 칸 3개와 "별 0/3"·시계, 아래쪽에 방향 버튼. 1280x720에서 칸 크기는 쉬움 120(상한), 보통 92, 어려움 65px. 화면비가 바뀌면(`expand`) 남는 공간에 맞춰 다시 계산한다.
- **시간**: 첫 이동 입력(벽에 부딪힌 것 포함)부터 출구 도착까지. 그 전에는 "움직이면 시계가 가요"라고 보여 주어 미로를 먼저 살펴볼 수 있다. "그만하기" 창이 열린 동안은 게임이 멈추므로 시간도 멈춘다. 시계는 작고 옅게 정수 초로 보여 준다.
- **랭킹**: 별 많은 순, 같으면 걸린 시간 짧은 순(`RankOrder.ScoreDescTimeAsc`, 기록의 `Score`에 별 수). 별을 모으도록 하려고 시간만으로 정하지 않았다. 탈출하면 별 0개여도 기록 대상이다.
  - **난이도별 랭킹**: 쉬움/보통/어려움이 각자 Top 10을 가진다(`maze:easy`, `maze:normal`, `maze:hard`). **같은 난이도의 미로 5개는 한 표를 같이 쓴다**(미로마다 길이가 조금 달라 짧은 미로의 기록이 유리할 수 있다. 개선 MZ-4). 캐릭터·배경으로는 나누지 않는다.
  - 순위표와 메뉴 카드: "별 3 · 25.3초"(메뉴 카드: "어려움 최고 별 3 · 25.3초").
- **결과 화면**: "탈출 성공!" / "걸린 시간" / "N.N초"(count-up) / 별 3개 줄이 함께 켜지며 "별 N/3"(공통 `ResultSpec.StarsLabel`을 추가했고, 별이 5개 이하면 별을 크게 그린다). 버튼: 다음 미로 / 다시 하기 / 메인으로.
- **개발용**: `-- --game=maze --autoplay`는 출구를 피해 가장 가까운 별부터 최단 경로로 줍고 출구로 간다. 세 번째 입력은 반드시, 그 뒤로는 5% 확률로 벽에 부딪혀 본다. 난이도와 미로는 `settings.cfg`의 `[maze] level`(0~2)과 `next_*`를 따른다.
