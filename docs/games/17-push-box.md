# 상자 밀기

> 원본: `docs/Daoni_MiniGame_확장기획서.md` 추가 추천 11절(Sokoban). 게임 방식만 가져오고 아이용으로 바꿨다.

## 게임 목표

토끼를 움직여 나무 상자를 밀어 별 자리에 모두 넣는다. 상자는 밀 수만 있고 당길 수는 없다.

## 게임 플로우

`꾸미기(난이도 → 배경) → 판이 나타나고 상자가 톡톡 놓인 뒤 토끼가 떨어짐 → "상자를 별 자리에 넣어요!" → 이동·밀기 → 모든 상자가 별 자리에 → "다 넣었어요!" → 결과 화면`

- 미로 탈출과 같은 흐름이다. 카운트다운 없음, 시계는 첫 이동부터 간다.

## 조작

- 미로 탈출과 같다: 방향키와 WASD, 오른쪽 아래 큰 방향 버튼(▲ / ◀ ▼ ▶), 판 위 스와이프. 입력 한 번에 한 칸, 누르고 있으면 0.3초 뒤부터 반복.
- 되돌리기(`ui/undo.png`, PC: Z 또는 Backspace): 한 걸음씩, 횟수 제한 없음. 처음부터(`ui/reset.png`, PC: R).
- 입력은 터치 이벤트만 처리한다.

## 화면 구조

- 미로 탈출 배치를 그대로 쓴다: 판은 왼쪽에 가능한 크게, 오른쪽 열에 위부터 "보통 · 3번 판"·그만하기, 상자 칸("2/3"), 시계·걸음 수, 되돌리기·처음부터, 아래쪽 방향 버튼.
- 판 크기는 판마다 다르므로(최대 9 x 8) 칸 크기를 판에 맞춰 계산한다.

## 규칙과 판정

- 원본 규칙 그대로: 토끼는 빈 칸으로 한 칸 움직인다. 이동 방향에 상자가 있고 그 너머가 빈 칸(또는 별 자리)이면 상자를 한 칸 민다. 상자 두 개나 벽은 밀 수 없다.
- 밀 수 없는 쪽으로 가면 미로 탈출처럼 작은 "통"과 함께 살짝 밀렸다 돌아온다. 감점 없음.
- 상자가 별 자리에 들어가면 반짝이는 상자(`pushbox/box_done.png`)로 바뀐다. 다시 밀어내면 원래 상자로.
- **막힘 알림**: 상자가 별 자리가 아닌 구석에 끼어 다시 움직일 수 없게 되면(Core가 판정: 구석, 벽을 따라 별 자리 없는 줄 등 단순한 경우만), 그 상자가 졸린 얼굴처럼 살짝 흔들리고 친구가 "이 상자는 못 움직여요. 되돌려 볼까?"라고 하며 되돌리기 버튼이 반짝인다. 원본에는 없지만 아이가 왜 막혔는지 모르고 헤매지 않게 넣었다.
- 모든 상자가 별 자리에 들어가면 완성.

## 난이도

**난이도별 랭킹**(`pushbox:easy`, `pushbox:normal`, `pushbox:hard`). 난이도마다 직접 만든 판 5개, "다음 판"으로 차례로 돈다(5번 다음은 1번). 같은 난이도의 판들은 한 표를 같이 쓴다(미로 탈출과 같은 방식, 판마다 길이가 달라 짧은 판이 유리할 수 있다).

| 변형 | 상자 수 | 판 크기 | 최소 밀기 |
|---|---|---|---|
| 쉬움 | 1~2개 | 6x6 안쪽 | 3~8번 |
| 보통 | 2~3개 | 8x7 안쪽 | 8~20번 |
| 어려움 | 3~4개 | 9x8 안쪽 | 15~35번 |

- 판은 Core에 문자열 표(`#` 벽, `.` 별 자리, `$` 상자, `@` 토끼)로 둔다. 단위 테스트가 모든 판을 너비 우선 탐색으로 풀어 풀 수 있는지와 최소 밀기 범위를 확인한다.

## 점수와 랭킹

- 랭킹: 걸린 시간 짧은 순, 같으면 걸음 수 적은 순(`RankOrder.TimeAscScoreAsc`, 기록의 `Score`에 걸음 수). 끝까지 하면 기록 대상. 되돌린 걸음은 걸음 수에서 빼지 않고 그대로 센다(되돌리기는 자유지만 기록은 정직하게. 시간만으로도 자연스럽게 반영된다).
- 표시: "38.2초 · 54걸음". 결과 화면 "다 넣었어요!" / "걸린 시간" / "N.N초" / 보조 줄 "N걸음". 버튼: 다음 판 / 다시 하기 / 메인으로.

## 연출 강도

- 걷기(가장 자주): 미로 탈출 캐릭터 이동과 같이 0.14초 미끄러지며 작게 뛰기, "톡" 발소리. 방향에 따라 토끼 그림이 바뀐다(옆 걷기 / `rabbit_back` / `rabbit_front_walk`).
- 밀기: 토끼가 `rabbit_push` 포즈, 상자가 끌리는 "드르륵"과 작은 먼지.
- 상자가 별 자리에: 상자가 깡충 뛰며 반짝, 별이 튐, 올라가는 "띵동", 상자 칸이 하나 켜짐.
- 완성: 모든 상자가 차례로 뛰고 토끼가 환호(`rabbit_cheer`), 팡파르, 색종이.

## 원본에서 바꾼 점

- **되돌리기 무제한, 처음부터, 막힘 알림**: 소코반은 실수하면 풀 수 없게 되므로, 실패 대신 언제든 되돌릴 수 있고 막힌 것을 친절히 알려 준다.
- **작은 판과 적은 상자**: 아이 수준에 맞춘 판만 직접 만든다.

## 사용 리소스

- `pushbox/box.png`, `pushbox/box_done.png`, `pushbox/goal.png`, 바닥·벽은 `maze/floor.png`, `maze/wall.png`(미로 타일 재사용), 토끼는 `buddy/rabbit_walk.png`, `rabbit_push.png`, `rabbit_back.png`, `rabbit_front_walk.png`, `rabbit_cheer.png`, `rabbit_idle.png`. `ui/undo.png`, `ui/reset.png`, `ui/btn_up/down/left/right.png`, `menu/push_box.png`.
- **리소스가 없을 때**: 바닥·벽은 미로 탈출의 코드 그림(`MazeBoard`의 크림색 바닥, 초록 울타리)을 같이 쓴다. 상자는 갈색 둥근 사각형 + 나뭇결 줄 + X자 판, 별 자리는 `ui/star.png`를 옅게. 토끼는 미로 탈출 캐릭터처럼 `animal/rabbit.png`.

## 완료 조건

- 이동, 밀기, 벽·상자 두 개 못 밀기, 상자 별 자리 표시.
- 되돌리기(무제한), 처음부터, 막힘 알림.
- 모든 상자를 넣으면 결과 화면, 난이도별 Top 10 기록, 다음 판 순환.
- 모든 판이 풀린다(단위 테스트). `--game=pushbox --autoplay` 스모크 테스트 오류 없음.

- 기획과 달라진 점
  - 판 크기 "6x6 안쪽"은 울타리 줄을 포함한 크기로 했다(쉬움은 안쪽 4x4).
  - 막힘 판정은 "별 자리가 아닌 막다른 칸"(구석, 별 자리 없는 벽 줄)과 "벽·상자로 꽉 찬 2x2"다. 구석·2x2는 "이 상자는 못 움직여요. 되돌려 볼까?", 벽을 따라 미끄러질 수는 있는 경우는 "이 상자는 별 자리에 못 가요. 되돌려 볼까?"로 말을 나눴다. 상자는 흔들리며 살짝 푸르스름해지고 "쿨쿨"이 뜨고, "음?" 소리, 되돌리기 버튼이 막힘이 풀릴 때까지 반짝인다.
  - 되돌리기·처음부터 버튼을 방향 버튼 ▲ 양옆 빈 칸에 넣었다(응원 친구 말풍선이 버튼을 가리지 않게). 응원 친구는 방향 버튼 위에 선다(기본 판다, 토끼가 주인공이라서). 꾸미기에 "응원 친구"를 더했다.
  - 처음부터(R)는 확인 없이 바로 하고, 되돌리기 한 번으로 처음부터 전 상태로 돌아온다. Z·Backspace는 누르고 있으면 계속 되돌린다.
  - 걸음 수에는 부딪힘은 세지 않는다(움직인 걸음과 민 걸음만).
  - 소리는 기존 합성음: 걸음 `Step`, 밀기 "드르륵" 대신 `CardFlip`(낮고 작게), 별 자리 `MatchChime`(넣은 개수만큼 올라감), 부딪힘 `WallBump`, 막힘 `Retry`, 되돌리기 `CardFlip`, 처음부터 `Whoosh`.
- 자동 플레이: 판이 시작되면 풀이기의 최단 걸음을 따라 간다. 가는 길에 한 번씩 엉뚱한 한 걸음 → 되돌리기, 막히는 곳으로 밀기(막힘 알림 3초) → 되돌리기, 벽에 부딪히기, (길이 남았으면) 처음부터 → 되돌리기를 해 본다. 배속 없이 `--quit-after 8000` 안에 결과·기록까지 간다.
