# 필요한 리소스 목록

현재 리소스는 `art-source/`의 스프라이트 시트 5장과 하늘 배경 1장이다. 사운드는 모두 코드로 합성한다(`scripts/Core/SfxSynth.cs`).
아래 리소스가 생기면 `art-source/`에 원본을 넣고, 잘라 쓸 그림은 `assets/`에 영문 이름으로 넣는다. 받으면 체크한다.

## 공통

- [ ] **투명 배경 캐릭터**(토끼, 고양이, 판다 등 전신). 기본, 점프, 환호 포즈. 지금은 동물 카드 그림을 써서 스티커처럼 보이고, 고양이는 없다(미로 캐릭터도 같은 그림). → 개선 B-8, MZ-3
- [ ] **배경 이미지**(가로 1280x720 이상): 우주, 바다, 하늘. 지금은 공원만 이미지이고 나머지는 코드로 그렸다. → 개선 B-7
- [ ] **효과음**: 풍선 펑, 카드 뒤집기 "팔락", 짝 성공 "띵동", 미로 발소리·벽 "통"·별 줍기 "반짝", 과일 받기 "뿅", 황금 과일 "띠링", 공룡 점프 "보잉"·장애물 통과 "띵"·넘어짐 "뿌우웅", 버튼, 딩동댕(정답), 문제 등장 "띵동", 다시 고르기 "음?", 시작, 끝, 팡파르. 지금은 합성음이다.
- [ ] **BGM 2곡**(메뉴, 게임), 반복 재생용
- [ ] **둥근 한글 폰트 파일**(무료 라이선스). 지금은 시스템 글꼴이라 안드로이드에서 모양이 달라진다.
- [ ] 앱 아이콘
- [ ] 타이틀 로고 "토이 박스"(선택) → 개선 M-2

## 게임별

- [ ] 미로 탈출: **벽·바닥 타일, 출구(문/깃발)**. 지금은 코드로 그린다(`MazeBoard`: 크림색 바닥과 둥근 초록 울타리 벽, `MazeExit`: 금색 매트와 분홍 깃발). 투명 배경 캐릭터(위 공통)도 미로 캐릭터로 쓴다. → 개선 MZ-3, MZ-5
- [ ] 숫자/색깔 퀴즈: **숫자 6~9 카드**(`assets/sprites/quiz/num_6.png`~`num_9.png`, 1~5와 같은 스타일). 지금은 어려움(1~9)에서 6~9를 코드로 그린다(`QuizCard.DrawNumberCard`). 받으면 `QuizCard.PaintedNumbers`를 9로 바꾼다. → 개선 Q-5
- [ ] 동물 짝 맞추기: 동물 이름 음성(또는 울음소리) 8종. 지금은 짝을 찾으면 이름이 글자로만 나온다. → 개선 A-3
- [ ] 숫자/색깔 퀴즈: 문제 읽어 주는 음성("빨간색", "숫자 3" 등, 색 6개 + 숫자 1~9). → 개선 Q-2
- [ ] 공룡 점프: **넘어지는 포즈**(엉덩방아 등. 지금은 구르다가 엎드린 그림 `dino_crouch.png`으로 대신함) → 개선 D-3
- [ ] 공룡 점프: **다른 색·종류 공룡**(공룡 선택용, `dino_run`·`dino_jump`·`dino_crouch`와 같은 포즈 세트로. 예: 파랑·분홍 공룡, 트리케라톱스). 지금은 초록 공룡의 피부색만 셰이더로 바꿔 5가지 색을 만든다(`Dino.MaterialFor`) → 개선 D-4
- [ ] 공룡 점프: 이어 붙일 수 있는 땅 타일(양 끝이 잘린 모양). 지금은 `ground.png`를 겹쳐 이어 붙여 이음매가 보인다 → 개선 D-5
- [ ] 과일 받기: 황금 사과(지금은 동전 `fruit/coin.png`으로 대신 씀) → 개선 F-7, 다른 모양 바구니(지금은 한 그림을 셰이더로 색만 바꿈) → 개선 F-8
