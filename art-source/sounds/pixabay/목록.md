# 넣어 줄 소리 목록

이 폴더(`art-source/sounds/pixabay/`)에 **아래 파일 이름 그대로** 저장해 주세요. 확장자는 mp3, ogg, wav 아무거나 됩니다(예: `button.mp3`).
다 못 채워도 괜찮습니다. 없는 소리는 지금처럼 코드 합성음이 나옵니다.
받은 페이지 주소를 "주소" 칸에 붙여 두면 나중에 라이선스 확인할 때 편합니다(선택).

- 효과음: https://pixabay.com/ko/sound-effects/ (영어로 검색하는 게 결과가 많음)
- BGM: https://pixabay.com/ko/music/
- 고르는 기준: 효과음은 1초 이내, 앞에 무음 없는 것. 날카로운 소리, 실패 부저, 폭발음은 피하기. BGM은 반복해도 자연스러운 것(loop)
